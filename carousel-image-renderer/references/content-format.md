# Markdown 渲染协议

本文件只定义输入格式。

## Front matter

每份输入以 front matter 开头：

```md
---
title: 一份公司研究
subtitle: 两个数字，看懂成本变化
kicker: 公司公告 2026年8月
cover: true
---
```

- `title`：必填，只用于封面，支持行内标记。
- `subtitle`、`kicker`：可选封面文字；kicker 默认“图文报告”。
- `cover`：保持 `true`。
- `source_pages`：可选正整数，显示原始资料页数。

每个字段只占一行。

## Markdown

支持段落、二至六级标题、常用行内格式、链接、列表、任务列表、引用、分隔线、表格、图片、围栏代码、脚注和安全 HTML。优先使用 Markdown。

- 图片独占一行；相对路径以输入文件所在目录为基准。title 优先作为图注，没有 title 时使用 alt。
- 表格保持在单页内，尽量不超过 5 列、10 行。
- 不可拆分的图片、表格、代码和自定义块必须能放入单页。

## 行内标记

```md
{accent}品牌蓝强调文字{/accent}
{circle}关键数字{/circle}
{wavy}手绘下划线{/wavy}
==高亮文字==
```

在同一段内闭合自定义标记。

## 块级指令

除 `:::pagebreak` 外，块级指令使用开始行和独立的 `:::` 结束行：

```md
:::risk
需求回落可能压低价格。
:::
```

| 指令 | 用途 |
|---|---|
| `:::section` | 开启新的叙事问题。 |
| `:::lead` | 给出继续阅读的理由。 |
| `:::metrics` | 并排展示三组以上数据；每行写 `- 标签 \| 值`。 |
| `:::marker` | 强调一个核心事实或结论。 |
| `:::callout` | 承载可能影响投资判断的观点；全文至少一个非空块。 |
| `:::risk` | 承载风险；全文至少一个非空块。 |
| `:::source` | 说明正文特有的统计口径。 |
| `:::thumbnails` | 生成末页（endcard）：原始资料预览导流页。 |
| `:::pagebreak` | 在完整语义之间手动分页；无需结束行。 |

`:::section` 内直接写标题文字，不支持 `#` Markdown 标题语法；使用 section 或独立的二至六级标题，不能叠加：

```md
:::section
成本曲线开始变化
:::
```

`:::thumbnails` 必须唯一、非空且位于全文最后，至多 4 张缩略图。直接使用 `source-manifest.json` 的 `thumbnailMarkdown`，不要改写其中的路径。

优先自动分页，只在存在不可接受的叙事断点时使用 `:::pagebreak`。
