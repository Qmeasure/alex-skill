# 叙事与编辑规范

本文件是内容和文风的唯一规范源。流程见 [../SKILL.md](../SKILL.md)，Markdown 语法见 [content-format.md](content-format.md)，最终审计见 [audit-checklist.md](audit-checklist.md)。

## 编辑定位

默认受众是关注市场、有持仓或准备投资的泛金融读者。信源题材不限：公司、科技、政治、消费、国际冲突、人物和社会新闻都可以报道。写作目标是帮助读者看懂事件如何影响市场、行业、企业、资产价格或生活成本。

没有直接投资关系时，可以通过可靠资料建立间接因果链。每个箭头都必须有事实支撑；找不到支撑就保留新闻价值，不强行落到买卖建议。

整体口吻像懂行的投资老友复盘：清楚、直接、有判断边界，不像会议纪要，也不假装掌握信源之外的信息。

## 事实边界

- 本地信源在本流程中具有最高可信度。默认接受其内容，不要求外部交叉验证，也不因外部资料不一致而质疑、降级、删除或纠正本地信源。
- 忠实保留信源的表达层级：事实、预测、观点、估算和援引分别按原意转述；不把预测或观点改写成已经发生的事实。
- 原始材料和通过事实预审的联网资料都可以进入正文，并可自然融合。
- 不编造数字、人物、事件、引语、品牌信息或因果关系。
- 新增联网事实先记录链接、支持内容和访问日期，再由独立 sub-agent 预审。
- 联网资料只用于补充背景、案例和泛金融因果链，不用于核验或纠正本地信源。外部资料与本地信源不一致时，仍以本地信源为最高优先级；只有差异本身影响理解时，才说明口径、时间或观点差异。
- 多份本地材料地位平等；存在冲突时按各自原意呈现差异，不根据文件格式或文件名判断主次。
- 本地信源明确给出的数字直接保留。只有原文本身存在口径、单位或指代不清时，才如实标明不确定性；不得仅因无法外部核实而删除或弱化。

## 封面

封面必须让泛金融读者迅速明白：

1. 谁在说，或事件主体是谁；
2. 这件事为什么值得关注；
3. 可能通过什么路径影响市场、企业、价格或成本。

三层文字分工：

- `kicker`：机构、时间、文档或事件类型。使用“报道、速览、数据整理、市场动态”等中性词；不用“解读、深度分析、研判、点评”。
- `title`：制造阅读动机，优先点名公司、人物、产品或事件主体。若未点名，subtitle 必须点明。
- `subtitle`：补充主体身份、可信度或影响路径。数字必须具体，三层之间不重复。

封面只出现一次文章总标题。正文使用 section 标题推进叙事。

## 正文组织

- 每个 section 只推进一个核心问题；section 标题直接说明这一段讲什么。
- 新 section 尽量紧跟 `:::lead`，用市场信号、投资者疑问、反直觉判断或生活成本建立阅读动机。
- 自动分页产生的续页不强制重复 section 或 lead，但开头必须语义完整，不能只剩无法识别的“它、这家公司、对方”。
- 每个最终页面首次提到核心主体时尽量使用实名，使中间页也能独立理解。
- 反直觉、循环或悖论式表达改写为线性因果链：“先发生什么 → 导致什么 → 影响什么”。
- 一段一个念头。长解释之后可用一句短句收束。
- 每页围绕少量核心数字展开，避免无关系的数据堆砌。
- 不用“一、二、三”作为整篇主要组织骨架；步骤类内容除外。
- section 标题不用“没人叫X的X、无人称为Y的Y、不算Z的Z”等自指结构。

## 移动端表达

- 优先用文字和简单表格；复杂图表缩小后难以阅读。
- 图片只在确实传递信息时使用，选择高对比、元素少的素材。
- 表格尽量不超过 5 列、10 行。
- 段落保持精炼；不可拆的表格、指标组、图片、代码、marker、callout 和 risk 必须能放进单页。
- 不使用“对话中”“节目中”“访谈中”“材料提到”等脱离读者上下文的来源包装。说话者或媒介并非理解结论所必需时，直接把事实和判断融入正文；也不要在标题、表头或风险提示中保留访谈形式。
- 同一页控制强调样式数量，`{circle}`、`{wavy}`、`{accent}` 只强调真正关键的信息。

## 称呼与可读性

- 正文禁止出现“你”。这是不可降级的品牌要求。
- 优先省略主语或直接点名“投资者、持仓者、中签者、消费者”等准确角色，不要机械地用泛称替换每一句。
- 不假设读者具备专业背景。非通识概念先用一两句大白话解释，再展开。
- 抽出任一段，普通金融读者应能知道主体是谁、数字在比较什么、结论依据是什么。

## 英文信源

英文或翻译件信源要额外处理术语和中文语序。qu-ai-wei 不负责翻译，初稿阶段必须完成这些工作。

- 有稳定中文译名的公司、机构和地点使用中文，如英伟达、谷歌、苹果、阿里巴巴、腾讯、华为、亚马逊云、欧盟、华盛顿。
- 中文语境中通用的 AI、GPU、OpenAI、ChatGPT、DeepSeek、token 等可保留。
- 普通金融读者看到会停顿的英文应翻译或解释。
- 主动句优先；拆开多层定语，避免照搬英文被动语序和抽象名词链。
- 技术缩写第一次出现时给出必要的大白话解释，但不要重复括注常识词。

## 观点与风险

### `:::callout`

可能影响买卖决定的判断必须放入 `:::callout`，包括“贵不贵、值不值、该不该买、还能不能撑住”等。纯事实因果分析不需要 callout。

### `:::risk`

每份轮播图至少包含一个非空 `:::risk`。所有风险相关内容——已发生的负面事实、未来下行可能和风险归纳——均放入 risk，由渲染器统一添加“AI提示风险：”。正文不要重复标签。

风险块必须基于材料，不能为满足格式凭空创造风险。若材料本身只有正面描述，使用经过预审的行业或执行风险补足。

## 组件选择

| 组件 | 用途 |
|---|---|
| `:::section` | 开启新的叙事问题。 |
| `:::lead` | 给读者继续阅读的理由；推荐但不要求每页出现。 |
| `:::metrics` | 三组以上确实需要并排比较的数据。 |
| `:::marker` | 强调单个核心事实或结论。 |
| `:::callout` | 标记可能影响投资决策的观点。 |
| `:::risk` | 标记风险内容；全文至少一个。 |
| `:::source` | 仅说明正文特有的数据口径，不重复封面来源。 |
| `{circle}` / `{wavy}` / `{accent}` | 少量行内强调。 |
