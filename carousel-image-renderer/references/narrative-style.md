# 叙事风格指南

## 核心原则

默认受众是**关注市场、有持仓或打算建仓的股民和潜在投资者**。像一个懂行的投资老友在跟你复盘一样写——读者应该觉得有人在帮他拆解机会和风险，而不是在听汇报。

## 标题与钩子策略

`:::section` 标题保留为简洁的话题标签。紧跟一个 `:::lead` 给读者一个关心的理由——一条让股民停下来的市场信号、一个跟持仓或打新直接相关的数字、或者一个反直觉的估值判断。

Front matter 中的 `kicker`（封面小标签）使用中性词——报道、速览、数据整理、市场动态。禁止使用带主观判断色彩的词——解读、深度分析、研判、点评。

好的 lead 可以把多个市场事件素材组合在一起，制造密集的冲击感，而不是只抛一个点。

```md
:::section
A股最大IPO
:::

:::lead
科创板史上最大 IPO，首日涨 466%，770 万散户每签浮盈超 2 万——但第二天就跌了。
:::
```

## 数字密度

每页数字不超过大约3个。需要展示数据时，把数字编进叙述里，而不是用 `:::metrics` 列表。只在三组以上可比数据确实需要并排对照时才使用 `:::metrics`。

推荐写法：

> 这家公司只有90个人，一年花在 AI 上的钱却有1100万美元——接近员工总支出的三分之一。

而不是用数据面板机械地列出 团队规模 / AI支出 / 占比。

## 英文术语处理

受众是泛金融读者，不是程序员。有明确中文翻译的英文**必须翻译**，只有习惯上不翻译的术语才保留英文。

**必须翻译的典型例子**（非穷举）：

| 英文 | 中文 |
|---|---|
| Nvidia | 英伟达 |
| Google | 谷歌 |
| Apple | 苹果 |
| Alibaba / Tencent / Baidu / ByteDance | 阿里巴巴 / 腾讯 / 百度 / 字节跳动 |
| Huawei | 华为 |
| AWS | 亚马逊云 |
| DC (Washington D.C.) | 华盛顿 |
| EU | 欧盟 |

**可以保留英文的术语**：AI、GPU、OpenAI、ChatGPT、GPT-5、DeepSeek、token 等——这些在中文语境中已经是通用说法，翻译反而造成理解障碍。

判断标准：如果一个普通股民看到这个英文会愣一下，就翻译。

## 翻译腔反模式

以下是**必须避免**的具体翻译腔模式。写完初稿后逐句扫描，命中任何一条就改。

| 模式 | 坏例子 | 改法 |
|---|---|---|
| 被动句式 | "被...震惊"、"被...所驱动" | 换成主动句："觉得不可思议"、"推动了..." |
| 多层定语嵌套 | "以往任何技术周期中的公司" | 拆开："过去任何一轮技术浪潮里的公司" |
| 英文比较级直译 | "比他以前见过的任何东西都要快" | 用中文最高级："是他从业以来见过最快的" |
| "某种/某个"起头 | "某种移动宽带互联网"、"某种可以物理复制的东西" | 说具体："移动宽带"、"芯片这种能批量生产的东西" |
| "这是一个..."弱开头 | "这是一个巨大的利好信号" | 砍掉框架词："这是大利好" |
| "X的应对方式是Y" | "OpenAI的应对方式是做下一代" | 用问答节奏："OpenAI怎么应对？继续做下一代。" |
| 抽象概括代替画面 | "市场拉力非常强大" | 给出画面感："市场需求是抢着来的" |
| "处于...阶段/状态" | "产品形态还处于非常早期" | 说人话："现在的产品还非常初级" |
| "在...上/方面比...更..." | "在定价上比传统软件公司更有创意" | 直接说："定价比传统软件公司敢想得多" |
| 术语堆叠 | "有计划的商品化倾销策略" | 拆成大白话："有意用低价开源把市场搅乱" |

一个简单的检验方法：把句子念出来，想象是在跟朋友聊天。如果念出来觉得别扭，就一定要改。

## AI 句式反模式

以下是 LLM 高频产出但正常人不会写的句式。和翻译腔不同，这些模式在纯中文生成中也会出现。写完初稿后扫描，命中就改。

### 对仗式否定-肯定结构

| 模式 | 坏例子 | 改法 |
|---|---|---|
| "不是A，而是B" | "前提不是房价高，而是房价一直涨" | 正向说："靠的是房价一直涨，光停在高位没用" |
| "并非A，而是B" | "并非需求消失，而是增速放缓" | 直接说："需求没消失，只是增速放慢了" |
| "不取决于A，而取决于B" | "不取决于估值多高，而取决于涨多快" | 口语化："跟估值多高没关系，关键是涨多快" |
| "不会因为A而B，而会因为C而D" | "不会因为需求不足而结束，而会因为回报下降而结束" | 砍掉对仗："终结点不是需求不够，是投资者觉得不划算了" |
| "与其说是A，不如说是B" | "与其说是科技公司，不如说是地产公司" | 口语化："说白了就是个地产公司" |

检验方法：如果一句话里同时出现"不是/并非/不会"和"而是/而会"，大概率是 AI 在用对仗结构制造"深刻感"。改成正向的、单方向的表述，读起来更像人话。

短句中的自然对比不算（如"不是崩盘，只是减速"——短、节奏感强、没有"而是"的对仗腔）。判断标准是：这句话像不像一个人在聊天时会说的？

### 标题自指式修辞

禁止在 `:::section` 标题中使用"没人叫X的X"、"无人称为Y的Y"、"不算Z的Z"这类自指结构。读者在没看正文之前无法理解标题在说什么，信息量为零。

标题应该直接点明这一页讲的是什么，用短句制造好奇心即可。

| 坏标题 | 好标题 |
|---|---|
| 没人叫"贷款"的贷款 | 藏在合同里的贷款簿 |
| 无人称作泡沫的泡沫 | 泡沫的另一个名字 |
| 不算亏损的亏损 | 账面盈利，实际烧钱 |

## 读者知识假设

不要假设读者具备任何专业背景知识。如果一个概念、一场行业争论、一段历史脉络不是常识，必须先用一两句大白话交代清楚，再展开论述。

坏例子：直接写"计算机行业选了加法机的路线，另一条路是神经网络"——读者不知道这两条路是什么。

好例子：先交代"计算机从发明那天起就面临一个选择：造计算器，还是造一个能像人脑一样思考的东西？"然后再讲两条路各自走了多远。

判断标准：如果删掉前后文，单看这一段，一个普通股民能不能看懂？看不懂就说明前提没交代够。

## 段落节奏

- 一段一个念头。两句话之间需要喘口气的话，就另起一段。
- 正文中**禁止使用"你"字**。用客观化表述替代——"投资者"、"持仓者"、"中签者"，或者直接省略主语。
- 长短交替：一段较长的解释之后来一句短的，制造节奏感。
- 用**大白话**写，像普通人讲故事的口吻。避免书面腔和翻译腔。能用短句说清楚的不用长句，能用常见词的不用生僻词。破折号不超过每页一处——大量破折号是典型的 AI 生成痕迹。

## 钩子结构

每页开头先让读者觉得"这跟我的钱有关"，然后再展开解释。有效的开头方式包括：

- 一个投资者正在纠结的问题（"47 元贵不贵"、"现在追还是等回调"）。
- 一组市场事件的密集组合，把纪录、价格、参与人数打包在两句话里制造冲击。
- 一个反直觉的估值或业绩判断，紧接着马上解释。

避免用干巴巴的定义、公司介绍、或者按时间线铺背景来开头。一个重大市场事件（"A股最大IPO"、"首日涨幅创纪录"）可以作为开头，但要立刻接上"跟读者有什么关系"。

主体指代必须明确：正文每一页首次提及主体公司或人物必须用实名，"这家公司""它""对方"只能用于同一页内的回指。读者可能从任何一页看起，抽出中间任一页单独读，也必须知道在讲谁。封面 `title` 按规则不放人名或机构名，但这个豁免仅限于 title——`subtitle` 必须点名主角是谁。

## 价值判断与合规

涉及"贵不贵、值不值、该不该买、能不能撑住"等投资决策方向的判断，**必须**用 `:::callout` 包裹。渲染器会自动加上"AI观点"前缀，明确标注这是 AI 生成的观点而非事实陈述。

纯事实因果分析（"流通盘小所以弹性大"）不需要包裹。判断边界：如果一句话可能影响读者的买卖决定，就放进 callout。

所有涉及风险的内容——无论是已发生的负面事实还是未来的下行可能——**必须**用 `:::risk` 包裹。渲染器自动加上"AI提示风险："前缀，视觉上用橙红色调与"AI观点"区分。

正文中不得出现未标注的价值判断或风险提示。

## 故事插入

当话题涉及一个有名的公司、人物或事件时，鼓励 Agent 联网搜索一段简短的故事或轶事来让话题更生动。遵守以下规则：

1. **信源质量** — 只从高置信度来源搜索（主流媒体、公司公告、知名行业刊物）。Agent 的训练数据能帮助判断哪些来源可靠。
2. **模糊化处理** — 当精确数字无法确认时，做圆整或弱化处理。写"亏损上百万"而不是"亏损523万"。
3. **中间产物** — 禁止将搜到的故事素材直接写入最终 Markdown。先写入一个草稿笔记文件，等审计 sub-agent 核查之后再纳入正文。
4. **篇幅限制** — 一段故事插入最多占轮播图的一页。超了就砍。
5. **搜不到就算了** — 找不到合适的故事就跳过，绝不编造。

## 组件使用

| 组件 | 叙事模式下的用法 |
|---|---|
| `:::section` | 每页使用，作为简短的话题标签。 |
| `:::lead` | 推荐在每个 section 后面跟一句读者视角的钩子。 |
| `:::metrics` | 可选。仅在3组以上可比数据需要并排对照时使用，否则把数字编进段落。 |
| `:::marker` | 可选。当一页需要视觉强调某个核心结论时使用。 |
| `:::callout` | 可选。在页面底部需要一个收尾观点时使用；如果页面本身已经有一个强力的叙事收尾，可以跳过。 |
| `:::risk` | 涉及风险的内容必须使用。渲染器自动加"AI提示风险："前缀，橙红色调。 |
| `:::source` | 需要标注数据来源时使用。 |
| `{circle}`、`{wavy}`、`{accent}` | 少用。每页最多一到两处。 |

## Callout 标签配置

callout 标签默认为"AI观点"，可在 front matter 中通过 `callout_label` 字段覆盖：

```md
---
title: ...
callout_label: 划重点
---
```

渲染器读取 `callout_label` 字段作为面板前缀。未设置时显示默认的"AI观点："。

## 好的示例

以下是将一段关于长鑫科技 IPO 的研报内容改写为股民视角叙事风格的示例：

```md
:::section
A股最大IPO
:::

:::lead
科创板史上最大 IPO，首日涨 466%，单日成交 1,412 亿创 A 股纪录。770 万散户每签浮盈超 2 万。
:::

8.66 元发行价买入，一天变成 49 元。盘中市值一度超过工商银行，成了 A 股最大的公司。

但第二天就跌了 4.1%，收于 47 元。半导体板块集体下跌——中芯国际跌 5.7%，华虹跌 8.9%。长鑫的巨量成交，把整个板块的流动性都吸走了。

涨这么猛，一个关键原因是流通盘极小。首日自由流通股只占总股本的 6.73%，93.3% 的股份被锁定。770 万散户的买卖博弈集中在这一小撮筹码上，价格弹性被放大到极致。

:::callout
从当前位置往上走，赌的不是公司好不好，而是周期高位还能撑多久。
:::

:::risk
周期见顶、出口管制收紧、流通盘解锁后抛压集中——三重风险叠加，追高需谨慎。
:::
```

## 审计 sub-agent

最终 Markdown 写好并渲染完成后，需要启动一个独立的 sub-agent 对产出做审计，检查以下基线：

**结构与合规：**

- 主体指代是否明确？抽出中间任一页单独读，能否知道在讲哪家公司、哪个人？正文每页首次提及主体是否用了实名，封面 subtitle 是否点名了主角？
- 是否有页面的开头完全没有读者视角的切入（没有问题、没有生活场景、没有与读者相关的市场信号）？
- 是否使用了僵硬的编号结构（一、二、三 / 1. 2. 3.）作为主要的组织方式？
- `kicker` 是否使用了中性词（报道、速览、数据整理）？是否混入了"解读"、"研判"等带判断色彩的词？
- 是否有价值判断（贵不贵、值不值、该不该买、能撑多久）出现在正文段落中而没有用 `:::callout` 包裹？
- 正文中是否出现了"你"字？如有，标记并改为客观化表述（"投资者"、"持仓者"等）或省略主语。
- 涉及风险的内容是否全部用 `:::risk` 包裹？是否有风险提示遗漏在正文段落中？
- 如果使用了联网搜索的故事素材，中间产物文件是否存在？关键事实是否经过了交叉核查？
- 是否存在大量破折号（每页超过一处视为过多）？破折号堆积是典型的 AI 生成风格，应改为句号断句或口语化连接。

**翻译腔与文风（逐句扫描）：**

- **英文术语**：是否存在有明确中文翻译却没翻译的英文？（如 Huawei→华为、Alibaba→阿里巴巴、DC→华盛顿、Apple→苹果、Google→谷歌、Nvidia→英伟达、AWS→亚马逊云、EU→欧盟）逐个标记。
- **被动句式**：是否存在"被...震惊"、"被...驱动"、"被...取代"等被动结构？标记并改为主动句。
- **多层定语嵌套**：是否存在"X的Y的Z"式定语链？标记并拆分。
- **英文比较级直译**：是否存在"比...以前见过的任何东西都要快"这类结构？改为中文最高级（"是见过最快的"）。
- **抽象模糊代词**：是否存在"某种"、"某个"、"这个认知"、"一种完全不同的"等模糊起头？改为具体表述。
- **"这是一个..."弱开头**：是否存在"这是一个巨大的利好"这类句式？砍掉框架词。
- **术语堆叠**：是否存在"有计划的商品化倾销策略"这类连续术语？拆成大白话。
- **"处于...阶段"等书面句式**：是否存在"处于非常早期"、"在...上比...更..."等翻译结构？改为口语化表述。
- **整体读感**：把每句话念出来，像不像在跟朋友聊天？如果念出来别扭，标记。

**AI 句式：**

- **对仗否定-肯定**：是否存在"不是A，而是B"、"并非A，而是B"、"不取决于A，而取决于B"等对仗结构？改成正向单方向表述。短句自然对比除外（如"不是崩盘，只是减速"）。
- **标题自指**：`:::section` 标题是否使用了"没人叫X的X"、"无人称为Y的Y"等自指修辞？标题应直接点明内容。

**读者知识假设：**

- 是否有段落默认读者知道某个专业概念、行业术语或历史脉络，但没有先交代清楚？一个普通股民单独看这一段能不能看懂？

审计是一个宽松的质量关卡——标记问题让 Agent 修改，而不是执行硬性的机械阈值。

## 备选：泛大众受众

当用户明确要求面向非金融背景的普通读者时，切换到泛大众模式。核心区别：

- **钩子**从市场事件变为生活场景——价格变化如何影响读者日常消费。
- **术语**需要更多解释。股民模式下可以直接说"PE 34倍"，泛大众模式下需要括号注释"市盈率，股价除以每股利润，数字越高股票越贵"。

注意：泛大众模式同样禁止使用"你"字，用"消费者"、"普通用户"等客观称谓替代。

泛大众钩子示例：

```md
:::section
内存超级周期
:::

:::lead
明年换 iPhone，可能要多花一千块。不是因为什么新功能，是因为 AI 把内存抢光了。
:::

推理模型越来越长的上下文，把 KV 缓存撑得越来越大，内存需求正在指数级增长。

但产能一年只能涨20%到30%，远远跟不上。结果就是价格已经涨了4倍，接下来可能还要再涨2到3倍。

这不只是芯片厂的事。存储一涨价，手机、电脑、所有带内存的消费电子都跟着涨。普通消费者的钱包，就是这场 AI 军备竞赛的买单人之一。

:::callout
对普通人来说，AI 的代价不只是订阅费——下一台设备的硬件成本，可能已经被 AI 悄悄推高了。
:::
```
