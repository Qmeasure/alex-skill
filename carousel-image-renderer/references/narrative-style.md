# 叙事与编辑规范

本文件是内容和文风的唯一规范源。流程见 [../SKILL.md](../SKILL.md)，Markdown 语法见 [content-format.md](content-format.md)，最终审计见 [audit-checklist.md](audit-checklist.md)。

## 编辑定位

默认受众是关注市场、有持仓或准备投资的泛金融读者。信源题材不限：公司、科技、政治、消费、国际冲突、人物和社会新闻都可以报道。写作目标是帮助读者看懂事件如何影响市场、行业、企业、资产价格或生活成本。

没有直接投资关系时，可以通过可靠资料建立间接因果链，每一环都要有事实支撑。证据不足时保留新闻价值，止于事件影响。

整体口吻清楚、直接、有判断边界，像懂行的投资老友复盘。

## 事实边界

- 本地信源为最高依据，直接采用其内容；外部资料只补充背景、案例和泛金融因果链。
- 忠实保留信源的表达层级：事实、预测、观点、估算和援引分别按原意转述；不把预测或观点改写成已经发生的事实。
- 正文事实来自本地信源和通过预审的联网资料；数字、人物、事件、引语、品牌信息和因果关系均可回指这些材料。
- 多份本地材料地位平等；存在冲突时按各自原意呈现差异。
- 本地信源明确给出的数字直接保留；原文本身存在口径、单位或指代不清时，如实标明不确定性。
- 本地信源与外部资料不一致时，以本地信源为最终表述；差异影响理解时说明口径、时间或观点差异。

## 封面

封面让泛金融读者迅速明白：

1. 谁在说，或事件主体是谁；
2. 这件事为什么值得关注；
3. 可能通过什么路径影响市场、企业、价格或成本。

三层文字分工：

- `kicker`：标明机构、时间、文档或事件类型，使用“报道、速览、数据整理、市场动态”等中性来源标签。
- `title`：制造阅读动机，优先点名公司、人物、产品或事件主体。
- `subtitle`：补充主体身份、可信度或影响路径，并在 title 未点名时补齐主体。数字具体，三层之间不重复。

封面只出现一次文章总标题。正文使用 section 标题推进叙事。

## 正文组织

- 每个 section 只推进一个核心问题；section 标题直接说明这一段讲什么。
- 新 section 尽量紧跟 `:::lead`，用市场信号、投资者疑问、反直觉判断或生活成本建立阅读动机。
- 自动续页可以省略 section 或 lead，开头保持语义完整并明确主体。
- 每个最终页面首次提到核心主体时尽量使用实名，使中间页也能独立理解。
- 反直觉、循环或悖论式表达改写为线性因果链：“先发生什么 → 导致什么 → 影响什么”。
- 一段一个念头。长解释之后可用一句短句收束。
- 每页只保留服务核心问题的少量数字。
- 整篇以问题推进；步骤类内容可以编号。

## 移动端表达

- 优先使用适合手机阅读的文字和简单表格。
- 图片选择高对比、元素少且直接传递信息的素材。
- 表格尽量不超过 5 列、10 行。
- 段落保持精炼；不可拆的表格、指标组、图片、代码、marker、callout 和 risk 必须能放进单页。
- 直接陈述事实和判断；仅在说话者或媒介影响理解时保留归因。标题、表头和风险提示直接表达内容。
- 同一页控制强调样式数量，`{circle}`、`{wavy}`、`{accent}` 只强调真正关键的信息。

## 称呼与可读性

- 正文禁用“你”。
- 需要主语时，使用“投资者、持仓者、中签者、消费者”等准确角色；其余句子省略主语。
- 非通识概念首次出现时，先用一两句大白话解释，再展开。
- 抽出任一段，普通金融读者应能知道主体是谁、数字在比较什么、结论依据是什么。

## 英文信源

英文或翻译件信源在初稿阶段完成术语翻译和中文语序调整。

- 有稳定中文译名的公司、机构和地点使用中文，如英伟达、谷歌、苹果、阿里巴巴、腾讯、华为、亚马逊云、欧盟、华盛顿。
- 中文语境中通用的 AI、GPU、OpenAI、ChatGPT、DeepSeek、token 等可保留。
- 普通金融读者看到会停顿的英文应翻译或解释。
- 主动句优先，拆开多层定语，使用自然的中文语序。
- 非通识技术缩写首次出现时给出必要的大白话解释。

## 观点与风险

### `:::callout`

把可能影响买卖决定的判断放入 `:::callout`，包括“贵不贵、值不值、该不该买、还能不能撑住”等。纯事实因果分析使用普通正文。

### `:::risk`

每份轮播图至少包含一个非空 `:::risk`。risk 统一收纳已发生的负面事实、未来下行可能和风险归纳，渲染器自动添加“AI提示风险：”。

风险块基于材料；材料只有正面描述时，使用经过预审的行业或执行风险补足。

## 组件选择

| 组件 | 用途 |
|---|---|
| `:::section` | 开启新的叙事问题。 |
| `:::lead` | 给读者继续阅读的理由；按需使用。 |
| `:::metrics` | 三组以上确实需要并排比较的数据。 |
| `:::marker` | 强调单个核心事实或结论。 |
| `:::callout` | 标记可能影响投资决策的观点。 |
| `:::risk` | 标记风险内容；全文至少一个。 |
| `:::source` | 仅说明正文特有的数据口径，不重复封面来源。 |
| `{circle}` / `{wavy}` / `{accent}` | 少量行内强调。 |
