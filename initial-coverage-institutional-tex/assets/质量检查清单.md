# 质量检查清单

交付前逐项核对。分阶段列，每阶段产物落地时先核对本阶段的，最终报告交付前再核对全表一遍。任一项不达标，补充完善后再交付。

## 不通过就不交付的检查

这几条必须全过，不是软标准，上一次出事就出在"数据真实只靠自觉"。

- [ ] `python scripts/build_report.py <报告目录> --name …` 全部 PASS（含反编造 lint、版式量测、渲染检查、第一人称、无 Word / Markdown 文件），命中已逐条清除
- [ ] 正文和图表里每个数都能在 `_data` 底稿溯源（数值、口径、时间点、来源对得上），没有底稿外的数
- [ ] 没有合成 / 插值 / 示意 / 凑数的数据；缺数的地方是留空或标「未获取」，不是编一个值
- [ ] 现价、市值、指数等时效数据取的是结算日线收盘一手源，不是盘中价或搜索摘要
- [ ] PDF 渲染成 PNG 逐页目视核验过

## 阶段 1 公司研究稿

- [ ] 按投资逻辑链组织（复盘→业务→财务），不是资料清单堆叠
- [ ] 历史复盘有沿革、关键节点、股价复盘
- [ ] 业务按分部拆分，每个分部的收入占比、变现模式讲清
- [ ] 股权结构、实控人、核心管理层背景到位
- [ ] 行业空间有市场规模数（带来源和年份）、增长驱动、政策
- [ ] 三份公司名单已分开：O=经营竞品、V=严格估值可比、T=核心概念股/产业链；每家公司有层级、纳入理由和主要不可比点
- [ ] 竞争对手覆盖直接竞品和关键经营数据；估值可比公司目标 5–10 家，纯粹可比不足时保留真实小样本并披露局限，不为凑数硬塞不可比的公司；产业链公司每家公司有产业链关系和可验证主题暴露
- [ ] 目标公司进入三份名单候选数据并标记为后续高亮行；暂存表覆盖市值、收入、归母净利润、增长、PE、PS 和行业关键经营指标
- [ ] 横向数据先增量写入暂存表，检查通过后才合并，未直接编辑或覆盖原始数据
- [ ] 风险 8–12 条，分类
- [ ] 每个关键数字有来源和日期，关键数据双源（且双源异源，非转引同一篇）
- [ ] 建了 `_data` 底稿（五字段），每个进稿数字能溯源；底稿外的数没落进稿子
- [ ] 关键数就近标了口径（招股书 / 年报、绿鞋前后、账面 / 经调整）
- [ ] 全文无 AI 味（对照 `研报写作规范.md` 自检）

## 阶段 2 盈利预测模型（Excel）

- [ ] 蓝色输入只在假设表，每条假设有依据
- [ ] 模型页全部为联动公式，改假设表任一蓝色数字全表重算
- [ ] 收入按分部建线，各分部独立增速驱动
- [ ] 三档情景（乐观/中性/悲观），每档假设可溯源，差异讲得出依据，不是基准 ±10% 机械摆动
- [ ] 利息、税项的处理已声明（计算 or 口径声明）
- [ ] 历史回测做了：用模型逻辑还原最近 1–2 个实际年度，分项偏差 <10%
- [ ] 基年/次年预测对照过一致预期和公司指引，偏离 >10% 写了分歧理由
- [ ] 配色规范：蓝=输入 / 黑=本表公式 / 绿=跨表引用
- [ ] recalc 零错误；data_only 读回关键输出与手算一致
- [ ] 币种、单位、财年口径已声明（财年非 12 月截止的专门标注）

## 阶段 3 估值与目标价

- [ ] 至少两种估值法（相对估值 + SOTP 或 DCF）
- [ ] 只有估值可比公司进入相对估值和分位；竞争对手和产业链公司未因直接竞争或同概念被误用于目标倍数
- [ ] 估值可比公司目标 5–10 家并给分位统计（最大/75 分位/中位/25 分位/最小）；纯粹可比不足时披露小样本局限，不硬凑；仅 1–2 家时改逐对比较，未虚构分位意义
- [ ] `横向比较_主数据` 含三份名单层级、唯一证券 ID、行情日、财务期间、币种/FX、来源及市值/收入/利润/PE/PS 原值与公式
- [ ] Excel 已建立 `横向比较_主数据`、`竞争对手`、`估值可比公司`、`产业链公司` 四个 sheets；后三个由主数据公式/查询派生，没有手抄第二份数值
- [ ] 四个 sheets 冻结表头、启用筛选、标单位与基准日、目标公司高亮；重复键/日期/期间/FX/PE差/PS差/估值可比公司有效样本检查列全 PASS
- [ ] 最终估值可比公司从阶段 1 的候选名单里有记录地筛出；新增、移除或改层级均写明原因，没有无解释换样本
- [ ] PE、PS 从原值重算并抽查至少 3 家；目标公司和估值中位数手算复核；负利润 PE 为 `N/M` 且未进入 PE 分位
- [ ] 双重上市/ADR 已去重，综合集团的分部口径或集团口径不一致已标注，GAAP/adjusted、LTM/FY1 未混用
- [ ] 分部 SOTP（多业务公司）：每个分部估值方法和倍数有依据
- [ ] DCF（如做）：WACC 拆解、永续增长/退出倍数、敏感性表齐
- [ ] 目标价能从估值方法回溯出来，不是主观臆定
- [ ] 给了评级（首次）、上行空间、3–5 条催化剂
- [ ] 现价是结算日线收盘口径（不是盘中价），标了日期；市值 = 结算收盘 × 股本（股本口径绿鞋前后标清）
- [ ] 内部一致性校验过：`prev_close ×(1+涨幅)` = 结算 `close` 本身，没用涨幅反推 close
- [ ] 估值页并入阶段 2 的 Excel，没另起文件
- [ ] 估值用的每股数、利润数与阶段 2 模型一致

## 写作（全文通用）

- [ ] 投资要点是"加粗判断 + 展开"
- [ ] 判断后跟数字和来源
- [ ] 无填充套话、无 -ing 伪分析尾巴、无机械三段式、无金句口号
- [ ] 句子节奏有长短变化
- [ ] 章节标题、小标题都带判断，非中性名词或翻译腔抽象词
- [ ] 无独立引言段；摘要开头有一句点题设问/钩子，正文直接从"一、公司概况"起
- [ ] 无"本文不讨论 / 不覆盖 X"式否定铺垫，直接正面写覆盖了什么（分析性否定不算）
- [ ] **全文 0 处「我们」**（`check_first_person.py` 断言，不靠肉眼）
- [ ] 无取数与筛选过程（「估值可比公司取四家」「数据取自 XXX」「筛选后保留」）
- [ ] 无困难叙述（「问题是」「跨度太大」「不具备参考意义」「只能」「因此只好」）
- [ ] 无自指（「全篇最关键」「值得单独标出来」「接下来要回答的是」「拆开看」）与自辩（「这不是额外的悲观假设」）
- [ ] 可比公司段是分组判断，谁有参考意义 + 原因数字，谁没有 + 原因数字；不是过程复述
- [ ] 小标题给结论，不是「遇到什么困难 + 怎么绕过去」
- [ ] **每个标题（含主标题、章标题、小节标题）都无比喻、无自指、无否定对仗**；单独拿给没读过正文的人看，能说出这节讲什么、结论是什么
- [ ] 标题能带数字的都带了数字，没有停在中性名词短语
- [ ] 无硬翻译 / 直译 calque（成本桥、顺风逆风、价值洼地、敞口、硬约束），行话（护城河、对标）保留
- [ ] 无装饰性比喻（删掉信息不减的，船票、埋下隐忧、压舱石）
- [ ] 无情绪化 / 暴力词（暴雷、杀估值、吃掉、蛋糕在缩），换成了字面说法
- [ ] 对冲词没堆砌（可能、或许、某种程度上一句留一个），数据的"约、近"保留
- [ ] 同一个东西从头到尾用同一个词，没换着叫
- [ ] 并列枚举用 bullet / 分段（每项加粗领起），连贯论证用散文，没塞成流水账也没拆碎
- [ ] 判断 / 风险都追了一层归因（机制 + 落点），不停在现象
- [ ] 总检查：把形容词、比喻、对仗拿掉后还剩具体信息，不是空话；逐句拿不准就查 `去AI味案例库.md`
