# TeX 版式标准

阶段 5 产出的 PDF 必须符合这份标准。它管排版机制：机构标识、配色、字体、字号、行距、页边距、首页双栏、正文窄栏、表格、图注、页眉页脚、禁止项、交付前检查。研报特有的首页信息编排、Key data 页、章节逻辑由 `../assets/报告模板与版式.md` 管，两份一起遵守；排版数值以本标准为准。

版式全部写在 `assets/tex-template/style/zfj-report.sty` 里，报告正文只调用它提供的命令，不在正文里写字号、颜色、间距。要改版式，先改这份标准，再改 sty，两边保持一致。

## 单位

Word 的「磅」是 1/72 英寸，在 TeX 里叫 `bp`；TeX 的 `pt` 是 1/72.27 英寸，比 `bp` 小 0.375%。本标准里所有磅值都是 `bp`，sty 里也一律写 `bp`。写成 `pt` 会让字号、行距、表格行高整体缩小，一页下来差出好几行。

DXA 是 Word 的计量单位，1 DXA = 1/20 bp = 0.05bp。原 Word 版的宽度常量（10546、7171 等）保留在下文，便于对照。

## 编译

- 引擎：Tectonic（XeTeX 内核），命令由 `scripts/build_report.py` 调用，不手动跑
- 文档类：`\documentclass{ctexart}`，**不加 fontset 选项**
- ctexart 默认把行距整体放大 1.3 倍，sty 里用 `\linespread{1}` 归 1，行高由下文的行高模型给出

## 配色

分两套：文字用两档蓝，图表内部用四色板。

**文字、线条与表格**（sty 里的颜色名）

| 颜色名 | 色值 | 用途 |
|------|------|------|
| `zfjDeep` | `#1B3A6B` | H1/H2/H3 标题、表头底色、页眉线、页码、右栏数据值、表格上下边线、右栏竖线 |
| `zfjBright` | `#2B6EF2` | 评级与目标价、首页横幅粗线、右栏分隔线与区块标签 |
| `zfjTint` | `#F2F6FC` | 表格隔行底色、目标公司行 |
| `zfjGray` | `#666666` | 来源、口径提示等小字，右栏标签 |
| `zfjRule` | `#D9D9D9` | 表格行间细线、右栏「结论 / 市场数据」之间的浅灰线 |
| — | 黑 | 正文 |

正文和章节文件里不写色值，只用这五个颜色名。

**图表内部**（细则见 `阶段4-图表生成.md`）

| 用途 | 色值 |
|------|------|
| 主数据系列（柱状、目标公司） | 深藏青 `#1F3A6E` |
| 次数据系列（折线）/ 强调 / 负值 | 珊瑚红 `#E15759` |
| 第三系列（堆叠第二层、并列第二组柱） | 中蓝 `#76A9E8` |
| 基准线、辅助线 | 灰 `#9AA5B1` |

图表配色独立于文字配色，不共用色值。柱用深藏青、线用珊瑚红，一冷一暖才拉得开。珊瑚红在同一张图里只承担次系列、强调、负值三个角色中的一个。旧版的青灰 `#1F4E5F` / `#2F5965` 不得出现在任何位置。

## 机构标识

logo 与机构名是硬要求，任何一页缺失都不算合格。资产在报告目录的 `brand/`（`scripts/new_report.py` 从 `assets/brand/` 拷入）：

- `zhifujie-logo.png`：智富界 logo，圆角白底方形图标，本身不含文字，机构名另设文本
- `zhifujie-qrcode.png`：社群二维码，只用于首页右栏底部

**首页品牌横幅**（`\zfjbanner{报告类型}{日期}`）：三格宽 45bp / 160bp / 其余（原 900 / 3200 / 6446 DXA），一行三格，① logo 1.4cm 见方 ②「智富界」16bp 加粗深蓝，左内边距 6bp ③「首次覆盖研究」9bp 深蓝 + 日期 7bp 灰，右对齐。三格垂直居中，上内边距 2bp、下内边距 4bp，下方一条 1.44bp 亮蓝粗线。logo 和机构名分放两格，放在同一行文字里会按基线对齐，文字掉到图片底部。

**正文页页眉**：首页不带；第 2 页起右上角 logo 小图标（高 0.5cm）+ 2.3bp 间距 +「智富界」9bp 加粗深蓝，文字基线距页顶 37.2bp；下方一条 0.48bp 深蓝线，从 x=32.64bp 到 562.8bp，上沿距页顶 41.52bp。

**页脚**：每页都有，右对齐页码 9bp 深蓝，基线距页底 27.33bp。页码用 `\thepage`，不手写。

页眉页脚由 sty 用 eso-pic 按绝对坐标画在每页上，不走 fancyhdr，位置与原 Word 版实测一致。

## 字体

- 中文：思源宋体 Source Han Serif CN，常规和加粗两种字重。sty 里用 `\setCJKmainfont` 显式指定，这是本 skill 唯一手动设字体的地方：格式要求思源宋体，而 ctexart 在 macOS 上自动选的是宋体-简
- 西文与数字：ctex 默认字体（Latin Modern），不另设
- 不设 fontset，不设 `\setmainfont`

**字形尺寸吸附**：原 Word 版由 Word for Mac 导出，字形尺寸吸附到 0.24bp 的整数倍（9bp 实际画成 9.12bp，8bp 画成 7.92bp，8.5bp 画成 8.4bp）。断行要和它一致，`\zfjfont` 的字形尺寸取吸附后的值，行高仍按标称字号算。

## 页面

- A4 纵向
- 页边距：上 1.8cm、下 1.6cm、左 1.2cm、右 1.2cm
- 版心宽 18.6cm = 527.24bp（原 Word 版 10546 DXA），下文宽度都以它为基准
- 页眉页脚不占版心（geometry 里 headheight、headsep、footskip 为 0）

## 行高模型

原 Word 版的纵向位置用一个模型就能全部复现，sty 的所有间距都按它算：

- 单倍行高 = 1.867 × 字号；多倍行距 = 单倍行高 × 倍数
- 行顶到基线 = 1.371 × 字号，与倍数无关；多出来的行高全部加在基线下方
- 相邻两段之间的距离取「上段段后」和「下段段前」中的较大值，不相加
- 页首的段前距离不计

sty 用一个小状态机实现这套规则：每个非正文块（标题、图、表、首页元素）结束时登记自己的段后，正文段落由 LaTeX 的 `para/before` 钩子接上。

## 正文与标题

| 元素 | 字号 | 字重 | 颜色 | 行距 | 段前 | 段后 | 命令 |
|------|------|------|------|------|------|------|------|
| 正文 | 9bp | 常规 | 黑 | 1.25 倍（21.0bp） | 0 | 3bp | 直接写段落 |
| H1 | 13bp | 加粗 | 深蓝 | 1.15 倍 | 10bp | 6bp | `\section{}` |
| H2 | 10.5bp | 加粗 | 深蓝 | 1.15 倍 | 8bp | 4bp | `\subsection{}` |
| H3 | 9.5bp | 加粗 | 深蓝 | 1.15 倍 | 6bp | 3bp | `\subsubsection{}` |

正文两端对齐，无首行缩进。标题不自动编号，编号（「一、」「1.1」）写在标题文字里；标题进 PDF 书签。标题后不分页。

## 正文窄栏

**正文文字只排在左侧 12.7cm 宽的窄栏里，右侧留白 5.65cm；图表和表格占满 18.6cm 版心。** 这是本版式最重要的识别特征。

- 正文段落：左缩进 7.1bp（142 DXA）、右缩进 160.2bp（3204 DXA），sty 在 `\begin{document}` 时全局设好
- 标题：左缩进 7.1bp，右侧不限宽
- 图、表、图注、首页各栏：左右缩进归零（sty 的宏内部已处理）
- 列表：随正文缩进，文字距正文左边界 36bp（720 DXA），悬挂 18bp

## 首页标题区

`\zfjcovertitle{主标题}{副标题}{股票标识}`：

| 元素 | 字号 | 字重 / 颜色 | 行距 | 段前 | 段后 |
|------|------|------|------|------|------|
| 主标题 | 20bp | 加粗 黑 | 1.25 倍 | 7bp | 2bp |
| 副标题 | 10bp | 常规 灰 | 280/240 | 0 | 3bp |
| 股票标识 | 9bp | 加粗 深蓝 | 260/240 | 0 | 6bp |

阶段 1 / 3 稿件没有首页，顶部用 `\zfjdrafttitle{稿件类型}{公司}{日期}`：一行 20bp 加粗标题 + 一行 10bp 灰色副行 + 1.44bp 亮蓝线，首页也画页眉。

## 首页双栏

标题区以下是一行三栏（`\zfjcovergrid{左栏}{右栏}`），顶端对齐：

- 左栏 358.55bp（7171 DXA，68%）放报告摘要
- 中间留白 21.1bp（422 DXA）
- 右栏 147.65bp（2953 DXA），左内边距 10bp（200 DXA），可用宽 137.65bp；左侧一条 0.48bp 深蓝竖线，贯穿整行高度（由较高的那栏决定）。这是全文唯一允许出现的竖线，x≈413.8bp

**内层宽度由外层推导，不另写数字**：右栏里键值行的宽度直接取右栏 `\hsize`，不单独写常量。两处各写各的数字是踩过的坑，差一个内边距就把整块顶出版心。

**左栏摘要**（`\zfjlead{加粗领起句}{展开}`）：8.5bp，行距 280/240（1.167 倍），段后 5bp，两端对齐。

**右栏**：

```
\zfjailabel                    ← 「AI 投资建议」8bp 加粗亮蓝 + 下方 0.48bp 亮蓝线
\zfjkv{投资评级}{…}{zfjBright}  ← 标签 64bp 宽灰色左对齐，数值右对齐；8bp 常规，上下内边距 1.3bp
\zfjkv{目标价}{…}{zfjBright}
\zfjkv{当前价 …}{…}{zfjDeep}
\zfjkv{上行空间}{…}{zfjDeep}
\zfjsplit                      ← 0.48bp 浅灰线，分开结论与市场数据
\zfjkv{总市值}{…}{zfjDeep}
\zfjkv{日均成交 3M}{…}{zfjDeep}
\zfjsidechart{figures/…png}    ← 宽 4.7cm，左对齐，段前 5bp 段后 2bp
\zfjteam                       ← 0.72bp 亮蓝分隔线 + AI 研究团队块 + 二维码 1.9cm + 扫码加入社群
```

标签与数值统一 8bp 常规，都不加粗，层级只靠颜色：评级与目标价亮蓝，其余深蓝。不给评级和目标价放大字号或加粗，右栏太窄，放大后会折行。

标的未上市时，右栏元素换成申购建议、合理市值区间等，相对表现图换成三年营收与净利迷你图，模板见 `front/sidebar-preipo.tex`，细则见 `../assets/报告模板与版式.md` 的「Pre-IPO / 拟上市标的分支」。

首页必须收在一页内；摘要写短了下半页会空，那是内容不足。首页结束用 `\zfjpagebreak`。

## 第 2 页：Key data

- 标题 `\zfjkeydatatitle[标题]`：13bp 加粗深蓝，段后 5bp，默认「Key data｜盈利预测及估值摘要」
- 主表：紧凑模式表格，占满版心
- 主表后 `\zfjkeydatagap`（段前 6bp 的空行）
- 下半 `\zfjkeydatagrid{左栏}{右栏}`：两栏各占半个版心（263.62bp），表宽扣掉 6bp 内边距为 257.62bp，保证不越出版心
- 小节标题 `\zfjkeydatablock{…}`：8.5bp 加粗深蓝，段后 2bp；小节之间 `\zfjkeydataspace`
- 整页收在一页内，结束用 `\zfjpagebreak`

## 表格

表格全部由 `scripts/export_excel_to_tex.py` 从 Excel「报告表格」sheet 生成到 `tables/<表ID>.tex`，正文只 `\input`，不手写表格代码。生成器按模式输出：

| 模式 | 用途 | 宽度 | 字号 | 口径小字 | 单元格内边距（上下 / 左右） |
|------|------|------|------|------|------|
| 标准 | 正文表 | 527.24bp | 8bp | 7bp | 4bp / 6bp（80 / 120 DXA） |
| 紧凑 | Key data 主表 | 527.24bp | 7.5bp | 7bp | 1.5bp / 4.5bp（30 / 90 DXA） |
| 半宽 | Key data 两栏 | 257.62bp | 7.5bp | 6.5bp | 1.5bp / 3.5bp（30 / 70 DXA） |

- 表头：加粗白字，底色深蓝，全部居中；正文表跨页时表头自动重复
- 单元格行距 1.1 倍；首列左对齐，其余列居中
- 隔行浅蓝底：数据行第 2、4、6…行；目标公司行（Excel 里行类型写「亮」）浅蓝底加粗
- 上下各一条 0.48bp 深蓝线，行与行之间 0.25bp 浅灰 `#D9D9D9` 线，**没有竖线**
- 口径小字放表内跨列末行，灰色，左对齐
- 行不跨页拆开
- 正文表标题「图表 N：…」在表**上方**，8.5bp 加粗居中，段前 6bp、段后 3bp；本页剩余空间放不下「标题 + 表头 + 前两行」时标题随表换页
- 正文表后留一个段前 3bp 的空行（16.8bp），与原 Word 版一致
- 窄列里的西文数字串（如「1.53x」「PEG」）放不下时，先向两侧内边距伸出，超过「列宽 + 两侧内边距」才逐字符折行，与 Word 的处理顺序一致
- 半宽表可以没有表头（键值表），正文表必须有表头

## 图片与图注

**图和表必须占满宽度。** 任何图片要么独占一行铺满 18.6cm，要么和另一张拼一行各占 9.3cm。**不允许缩小后孤零零居中**。

- 单图 `\zfjfig{figures/xx.png}{图注}`：宽 18.6cm（源图 figsize 宽 7.33in、300dpi），段前 3bp；图注在图下方
- 双图 `\zfjfigpair{左图}{左图注}{右图}{右图注}`：每格半个版心（263.62bp ≈ 9.3cm），图宽占满该格（源图 figsize 宽 3.66in），各自图注在本格图下方；图和图注不分页
- 图注「图表 N：主题」，8.5bp 加粗居中，1.15 倍，段前 3bp、段后 6bp
- 图和表共用一个「图表 N」序列，全文连续编号；首页和 Key data 页的表不编号
- 来源写在图片**内部**（7pt 灰小字，由画图脚本画进 PNG），不在图注下方另起一行
- 首页右栏的窄图不受本节约束，宽度取满右栏 4.7cm

## 分页

`\zfjpagebreak` 复现 Word「段落内分页符」的行为：本页放得下那一空行就留在本页再分页；放不下，空行挪到下一页顶部，下一页首行因此下移一个单倍行高（16.8bp）。首页和 Key data 页结尾都用它，正文里需要硬分页时也用它，不用 `\newpage`。

## 列表与链接

- 列表用 `itemize` / `enumerate`，不用手打符号冒充
- 链接用 `\href`，正文里不出现裸 URL

## 禁止项

- 手打项目符号（•、-、*、手打数字）冒充列表
- 裸 URL
- emoji
- 手写页码
- 正文或章节文件里写色值、字号、间距（一律用 sty 提供的命令）
- 手写表格代码或手敲关键数字（表格和数字由 Excel 导出）
- `\documentclass` 加 fontset 选项，或用 `\setmainfont` 改西文字体
- 旧配色 `#1F4E5F` / `#2F5965`
- 缩小后孤零零居中的图或表
- 任何图表的网格线；直角坐标图的上边线和右边线
- 深色底上直接放 logo
- 交付目录里出现任何 `.md`、`.docx`、`.doc` 文件

## 交付前检查

`python scripts/build_report.py <报告目录> --name <公司>_首次覆盖_<日期> [--pre-ipo]` 一条命令跑完下面全部检查，任一项 FAIL 不交付：

1. **无 Word / Markdown 文件**（`check_no_word_md.py`）
2. **Excel 导出**：「报告数字」「报告表格」导出成功；公式没有缓存值、错误值、宏名或表ID重复都会失败
3. **Tectonic 编译**成功
4. **编译日志**：无缺字（Missing character）、无超过 1bp 的 Overfull `\hbox`、无 Overfull `\vbox`
5. **渲染检查**（`check_render.py`）：页数区间、无空白/近空白页（单页字符数 ≥150）、首页元素齐全、第 2 页以 Key data 开头、文字不越出版心
6. **版式量测**（`check_layout.py`）：页眉线（首页无、其余每页一条）、右栏竖线（首页恰好一条且贯穿、其余页没有竖线）、正文窄栏、图宽（18.6 或 9.3cm）、字体（只有思源宋体与 Latin Modern）、配色、每页品牌标识、页码、首页不越出下边距
7. **第一人称**（`check_first_person.py`）：front/ 与 chapters/ 里 0 处「我们」
8. **tex 禁止项**（`check_tex_rules.py`）：正文里没有 `\newpage`、颜色和字号命令、手写表格、裸 URL、旧色值、emoji；`main.tex` 没有 fontset、没有 `\setmainfont`
9. **反编造 lint**（`anti_fabrication_lint.py`）：画图脚本、底稿 CSV、稿件与章节 tex

脚本能断言的一律以脚本为准。脚本之外，还要把 PDF 渲染成 PNG（`pdftoppm -r 100`）逐页看：中文显示、图表标签是否重叠、四色板是否生效、二维码是否清晰可扫。这些 XML 或词框里查不出来。
