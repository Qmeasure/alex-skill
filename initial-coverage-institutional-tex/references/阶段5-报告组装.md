# 阶段 5：报告组装

产物：报告目录里的 tex 工程和它编译出的 `[公司]_首次覆盖_[日期].pdf`，全流程交付同时保留 `data/` 下的联动 Excel 模型、底稿 CSV 和 `figures/` 下的图表。横向比较的完整数据与公式在 Excel，报告负责读者向精简展示并承载最终投资结论。不产出任何 Word 或 Markdown 文件。

报告只引用阶段 3 已完成校验的 Excel 及由其生成的图表。组装时发现数字需要更新，先经暂存表校验并写回 Excel，重跑导出脚本，再更新正文，不在 tex 里单独改数。

前置：阶段 1、2、3、4 产物全部齐，且各自达体量和质量。缺任一个，停下并报告缺口，不造占位内容。

这是全流程最重的一步，前面所有工作在这里落地。token 应充分投入，内容完整铺开，不压缩、不摘要化。

## 工具与目录

成品必须符合 `TeX版式标准.md`（机构标识、配色、字体、字号、行距、页边距、首页双栏、正文窄栏、表格、图注、页眉页脚、禁止项），动手前先读那份。研报特有的信息编排（首页三区、Key data 页、章节逻辑）看 `../assets/报告模板与版式.md`，排版数值以版式标准为准。

报告目录在阶段 1 开始时由 `python scripts/new_report.py <报告目录>` 建好，结构如下：

```
<报告目录>/
  main.tex                 只做装配：\documentclass{ctexart} + 版式包 + \input
  style/zfj-report.sty     版式包，不改
  brand/                   logo 与二维码
  front/meta.tex           主标题、副标题、股票标识、报告日期
  front/cover.tex          首页装配（横幅 → 标题区 → 双栏）
  front/summary.tex        首页左栏摘要，每段一个 \zfjlead{领起句}{展开}
  front/sidebar.tex        首页右栏（已上市）；Pre-IPO 用 sidebar-preipo.tex
  front/keydata.tex        第 2 页 Key data
  chapters/NN-xxx.tex      正文，每章一个文件，按投资逻辑链排序
  tables/<表ID>.tex        生成物：Excel「报告表格」导出
  data/keyfigures.tex      生成物：Excel「报告数字」导出的宏
  data/<公司>_盈利预测模型_<日期>.xlsx
  data/_data/*.csv         底稿与暂存表
  figures/*.png  figures/清单.csv  figures/build_charts.py
  drafts/公司研究_<日期>.tex / .pdf   drafts/估值分析_<日期>.tex / .pdf
```

`main.tex` 里 `\input` 的章节文件按实际章节增删，文件名用英文（`01-overview`、`02-industry`…），章名写在 `\section{}` 里。

## 实现要点

- **数字和表格从 Excel 来。** 阶段 3 完成后，在 Excel 里建两张面向报告的 sheet，单元格一律写成引用模型页的公式：
  - `报告数字`：A 宏名（英文字母）| B 数值 | C 显示格式（`0.00`、`#,##0`、`0.0%`，可空）| D 前缀 | E 后缀 | F 说明。已上市分支至少有 `Rating` `TargetPrice` `PriceLabel` `Price` `Upside` `MarketCap` `ADV`；Pre-IPO 分支至少有 `SubscriptionAdvice` `FairValueRange` `IssuePELabel` `IssuePE` `RaiseAmount` `IssueShares` `PostIPOShares` `ListingStatus` `LastRoundValuation`（和 `front/sidebar*.tex` 用到的宏名一致）
  - `报告表格`：A 列是行类型。`表` 行：B 表ID（英文、数字、下划线）、C 图表标题（空＝不编号，Key data 页的表留空）、D 列宽 DXA（逗号分隔，按比例缩放到表宽）、E 模式（标准 / 紧凑 / 半宽）；`头` 行：表头；`行`：数据行；`亮`：目标公司行（浅蓝底加粗）；`注`：口径小字。表与表之间空一行
  - 写完用内嵌 xlsx skill 的 `recalc.py` 重算，零错误后导出：`python scripts/export_excel_to_tex.py data/<模型>.xlsx <报告目录>`（`build_report.py` 会自动跑）
- **模板契约**：模板里的文件按固定名字引用，导出和出图时用同样的名字，否则编译报「文件找不到」
  - Key data 页的表ID：`kd_main`（紧凑）、`kd_basic`、`kd_cfbs`、`kd_is`（半宽）。Pre-IPO 分支同样用这四个ID，把 `front/keydata.tex` 里的「基本状况」小节标题改成「发行方案与股权结构」，`\zfjkeydatatitle` 可传入标题，如 `\zfjkeydatatitle[Key data｜宇树科技（待上市）]`；原稿需要更多小节时在 keydata.tex 里照 `\zfjkeydatablock` + `\input{tables/…}` 的写法增加，表ID自己起
  - 首页右栏窄图：已上市 `figures/cover_rel_perf.png`，Pre-IPO `figures/cover_mini_rev_ni.png`
  - 右栏宏名：见上一条「报告数字」的清单；Pre-IPO 分支用 `front/cover.tex` 时把 `\input{front/sidebar}` 改成 `\input{front/sidebar-preipo}`
  - 正文表的表ID随意（英文、数字、下划线），正文里 `\input{tables/<表ID>}` 对应
- **正文引用宏，不手敲关键数字。** 首页右栏和摘要里的评级、目标价、现价、上行空间写成 `\Rating`、`\TargetPrice` 这类宏；正文里其他数字照常写，但要和 Excel 一致
- **首页双栏**用 `\zfjcovergrid{\input{front/summary}}{\input{front/sidebar}}`，三栏顶端对齐，右栏竖线由版式包画，不自己加
- **正文窄栏**由版式包全局设好，正文直接写段落；不要在正文里改 `\leftskip` / `\rightskip`
- **图**：单张 `\zfjfig{figures/xx.png}{图注}`，成对 `\zfjfigpair{左图}{左图注}{右图}{右图注}`；图注不写「图表 N：」前缀，编号由版式包自动加
- **表**：`\input{tables/<表ID>}`；正文表的「图表 N」标题由生成器写在表上方
- **分页**只用 `\zfjpagebreak`，不用 `\newpage`
- **特殊字符**：正文里的 `%` `$` `&` `#` `_` 要转义（`\%` 等）；导出脚本生成的内容已自动转义
- **「未获取」这类文字值原样导出**，不参与数字格式化，不会变成 `NaN%`
- **编译与检查**：`python scripts/build_report.py <报告目录> --name <公司>_首次覆盖_<日期>`（拟上市加 `--pre-ipo`）。每改一版都重跑，再把 PDF 渲染成 PNG 逐页看

## 结构

按中式投资逻辑链组织（不是英文研报的固定清单）。骨架见 `报告模板与版式.md`，这里讲每部分放什么、怎么从前序产物取用素材。

### 首页

照 `../assets/报告模板与版式.md` 的首页规范做齐，三区加页底表：

1. **品牌横幅**：`assets/brand/zhifujie-logo.png`（1.4 cm）+ 深蓝「智富界」，同行右端「首次覆盖研究」+ 日期，下方亮蓝粗线
2. **标题区**：主标题（带判断）+ 副标题 + 公司全称/代码/行业归类
3. **双栏区**：左栏报告摘要（钩子设问领起 → 一/二/三 → 投资建议 → 风险提示，每层加粗判断领起，不写独立引言段，**要写满左栏版面**，投资建议层和风险提示层各带一句固定 AI 声明）；右栏十元素按固定顺序：**「AI 投资建议」区块标签**（8pt 加粗亮蓝 + 下方细线）→ 评级（首次）→ 目标价 → 当前价（带日期）→ 上行空间 →（浅灰细线分隔结论与市场数据）→ 总市值 → 日均成交（3 个月） → 相对表现图（阶段 4 窄版，**宽度取满右栏约 4.7 cm**）→ 亮蓝分隔线 → AI 研究团队块（「本报告由 AI 生成」+ 董AI/alex.dong@l2y.com + 李菲特/lester.li@l2y.com + 二维码 + 「扫码加入社群」）

首页页底**不放**盈利预测及估值摘要表，那张表在第 2 页。首页缺任一元素都不算完成。

### 第 2 页：Key data

四块内容全部收在一页，字号 7.5pt、单元格上下边距 30 DXA：

- **上半全宽**：公司盈利预测及估值摘要表（从阶段 2 模型 + 阶段 3 估值取数，含 A/E 年份标识），占满 18.6 cm
- **下半二列**（无边框表格，每栏 9.3 cm）：左栏放基本状况 + 现金流量表与资产负债表摘要，右栏放利润表摘要

这一页只放数据表，不写论述。全宽股价走势对比图放正文第一章，不放这里。

### 正文

正文不写独立引言段，直接从"一、公司概况"起（点题设问已并入首页摘要开头）。

**一、公司概况**，从阶段 1 的历史复盘、业务布局、财务分析整段取用，原文使用，不要重新摘要压缩。配阶段 4 对应图（沿革轴、股权图、分部收入、毛利率、财务趋势）。

**二、行业空间**，从阶段 1 的行业空间章取用素材。配市场规模图、产业链图、市占率图。多业务公司按分部讲空间。本章末尾从 Excel 的 `产业链公司` 摘取读者需要的精简产业链位置表和定价光谱，并写明产业链结论：目标公司位于哪个利润池、市场给哪些环节更高定价、关键变量如何传导到公司盈利和估值；完整名单留在 Excel。

**三、核心驱动 / 竞争壁垒**：全文最重的一章。把阶段 1 的竞争格局、差异化优势，加上对投资逻辑最关键的变量（技术壁垒、生态、新业务、AI 等）展开论证，回答"凭什么是它、凭什么是现在"。从 Excel 的 `竞争对手` 摘取关键经营对标，比较直接竞品的市占率、产品/客户/产能、收入增长、毛利率和关键经营指标；综合集团使用分部口径或明确标注集团口径不一致。配经营对标图、竞争格局图，并写明经营对标结论：目标公司相对竞品的优势、短板、优势形成机制和对盈利预测的影响；完整视图留在 Excel。

**四、盈利预测与估值**：
- 4.1 盈利预测：从阶段 2 模型取用分部收入预测、利润预测、关键假设，把假设逻辑讲透（每条假设的驱动和依据，按产品/分部细分）。配分部预测图、三情景图、回测图。摘要财务表（收入/利润/毛利率/EPS，历史 + 预测）8–15 张。
- 4.2 估值：从阶段 3 取用相对估值、SOTP、DCF 辅证、目标价、评级、催化剂。从 Excel 的 `估值可比公司` 摘取支撑目标倍数的关键列和分位，完整的市值、收入、利润、PE、PS、分位和公式留在 Excel；只有可比公司进入目标倍数。配可比公司增长—估值图、SOTP 图、敏感性热力图、足球场图，并写明估值结论：相对可比组的溢价/折价、是否被增长/利润率/壁垒/周期解释、目标倍数的依据和会触发估值组迁移的变量。
- 4.3 风险提示：8–12 条，分类。

**附**（可选）：盈利预测三表摘要。

### 图表嵌入

阶段 4 的 40–70 张全部嵌入正文相应位置，不是附在文件夹里。三份名单的完整表保留在 Excel；报告需要展示的精简表写进 Excel「报告表格」再导出成 tex 表格，不得把 Excel 大表截图成 PNG。所有图片和表格按正文出现顺序统一分配「图表 N」（版式包自动编号），全文连续编号；阶段 4 的资产 ID 和建议顺序不等于最终编号。只保留页码内容目录，不另做图表目录（list of figures）。

三份名单共用阶段 3 Excel 的 `横向比较_主数据` 作为数字唯一权威来源：第二章只从 `产业链公司` 摘取产业链字段，第三章只从 `竞争对手` 摘取经营字段，4.2 只从 `估值可比公司` 摘取估值字段。不要在三个章节重复粘贴同一张全字段大表，也不要在 tex 里重新抓取、重算或手录一套数字。

### 横向比较结论

交付前逐项确认三组结论均已进入正文，而不是只存在 Excel：

- 经营对标：经营强弱、优势机制、短板及对盈利预测的影响
- 可比公司估值：估值溢折价、目标倍数依据、重估/回落触发变量及对目标价/评级的影响
- 产业链：利润池位置、跨环节定价差异、传导变量及风险

小标题直接写结论，形如「小结：<结论>」。

每组至少 1 条带数字或图表证据的明确判断。缺任一组，不得交付。

**图和表一律占满宽度**：单张铺满 18.6 cm，成对的用 `\zfjfigpair` 各占 9.3 cm 并铺满该格。**缩小后孤零零居中在页面中间是禁止项**，那样左右各留一条无用空隙，是整份报告里最显廉价的地方。成对/可对照的图（分部增速对比、可比公司倍数、三情景、毛利率 vs 净利率等）优先拼一行；注意双图并列要用阶段 4 生成的窄版（`figsize` 宽 3.66 in），别把全宽图硬缩到一半。

## 体量门槛

- 25–45 页 / 1.5–3 万字 / 40–70 图全嵌入 / 关键财务表 8–15 张
- 每页基本都有图或表，版面 60–80% 有内容
- 达不到说明没有充分展开，补充完善后再交付

## 不得简化

- 不写"本章节将包括……"，写实际内容
- 不写"此处插入图表……"，嵌入真实图表
- 不写"详见财务模型……"，把关键数提进正文
- 不为省篇幅压缩章节、跳小节
- 阶段 1 的公司概况内容原文使用，不重新缩写

## 跨文件一致性（交付前重点查）

研报里的数必须与 Excel 模型一致。抽 10–15 个公司核心数（营收、归母净利、EPS、各分部收入、目标价、评级）在 PDF 和 Excel 间核对一遍；Excel 的四个横向 sheets 全量核对公司唯一键、层级、行情日、期间、币种、市值、收入、利润、PE、PS、关键经营指标和派生公式，报告只核对实际展示的字段。首页右栏、首页页底摘要表、Key data 页、估值章、摘要里的目标价和评级要一致。预测年份口径全文统一（哪年 A、哪年 E）。

**口径一致性专项**（最易出错）：同一个指标全报告口径必须统一，不能这页用招股书口径、那页用年报口径。每个关键数就近标口径（招股书截止日 / 年报、绿鞋前 / 后、账面 / 经调整）。这些口径在前面各阶段的 `_data` 底稿里都记着，组装时照搬、别混。

**数据真实性是不通过就不交付的检查**，和「PDF 逐页目视核验」同级：

1. `build_report.py` 会跑 `scripts/anti_fabrication_lint.py`（画图脚本、底稿 CSV、稿件与章节 tex），命中逐条清除才算过。
2. 抽查正文和图表里的数，每个都能在 `_data` 底稿找到对应条目（数值、口径、时间点、来源对得上）；底稿里没有的数，补来源或删掉。
3. 高风险数（现价、市值、目标价、份额）的来源是不是一手结算源？验证有没有换异源、没用同源摘要或同盘中价 feed 互证？

这三条不过不交付。

## 合规模块的边界

删掉合规样板：评级体系图例说明、分析师署名和执业编号、法律免责声明。

保留分析结论：投资评级（买入/推荐 首次）、目标价、风险提示章节，这些是研报的判断，不是合规填充。

## 自检

交付前对照 `assets/质量检查清单.md` 阶段 5 + 跨文件一致性 + 写作三部分，逐项核对。`build_report.py` 全部 PASS 是交付的前提，它断言的项（页数、空白页、首页元素、首页溢出、文字越界、页眉线、右栏竖线、正文窄栏、图宽、字体、配色、品牌标识、页码、第一人称、反编造）以脚本为准。脚本之外，把 PDF 用 `pdftoppm -r 100` 渲染成 PNG 逐页看：中文显示、图表标签是否重叠、四色板是否生效、二维码是否清晰可扫。任一项不达标，补充完善后再交付。
