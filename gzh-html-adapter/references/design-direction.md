# 设计方向判断

设计方向用于决定 HTML 的层级密度、阅读节奏、留白和分组方式。**颜色、字号和间距不在方向的决定范围内**，一律照抄 [visual-system.md](visual-system.md)。不得因为设计需要新增标题、摘要、金句、作者介绍、过渡段或行动号召。

## 判断依据

先看四件事：

- 文章类型：研究分析、观点评论、教程说明、访谈整理或叙事文章；
- 信息密度：长段落多，还是短段落、列表和小节多；
- 数据比例：表格、数值和图表在全文中的占比；
- 叙事方式：按论点展开、按步骤推进，还是按时间和人物推进。

据此用一句话概括方向。例如：

- 研究感：适合数据密集、论证层次明确的文章，重点是严谨的标题层级和便于核对的数据分组；
- 编辑感：适合观点评论和深度文章，重点是段落节奏、引文关系和阅读停顿；
- 教程感：适合步骤明确的说明文章，重点是顺序、操作区分和前后依赖；
- 叙事感：适合访谈、人物和事件文章，重点是时间、人物转换和舒展的阅读节奏。

这些名称只是概括，不限制具体表现。文章同时具有多种特点时，选一个最贴近全文的方向；确有必要时再补充另一个，不必生造新的风格名称。

## 表现规则

- 用标题层级、段落间距和分组边界表达结构，不靠新增文案解释结构。
- 根据内容密度调整留白。数据密集处便于横向核对，叙事段落保留足够的阅读停顿。
- 方向决定的是「分不分组、要不要转图表、段落之间留多少呼吸」，不是「用什么蓝」。
- 颜色、字号、间距、边框和标题形态一律取自 [visual-system.md](visual-system.md)，全文一致。
- 根 `<section>` 使用 `#FFFFFF`，或仅由 `#FFFFFF` 与 `#F2F6FC` 构成的原生 CSS 渐变。
- 阴影只用于帮助区分层级，不用来堆叠装饰效果。
- 不使用外部字体、图片、SVG、Canvas、data URI 或 CSS `url()`。

## 交付说明

在聊天中写一行：

```text
设计方向：研究感。原文数据和论证较密，采用紧凑层级和清楚的数据分组，便于连续阅读和核对。
```

这行说明不属于文章内容，不得写入正文 HTML 或预览页的复制区域。
