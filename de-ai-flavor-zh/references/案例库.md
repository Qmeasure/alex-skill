# 去 AI 味案例库

这是 `SKILL.md` 的配套例子。写完一段拿不准的话，回来对照着查：左边是改之前的 AI 味写法，右边是改之后落地的写法，最后一列说清楚毛病出在哪。

例子源自两处真实改稿：财经研报，和一套六册学员教材的四轮返工（后者贡献了论证记账、标题指代、无实体比喻、评价词、核心句口号化这几节）。毛病和改法对任何中文文章都通用——架子句、贴标签、情绪比喻、否定对仗、堆砌对冲，换个题材一样要改。

## 一、整句改写对照

| 改前（AI 味） | 改后（落地） | 毛病 |
|---|---|---|
| 四个看多支柱里三个事后大体兑现，买在 2021 年顶点却至今仍亏约一半——决定回报的是出价贵不贵，而非基本面对不对 | （整句删掉，直接进结论和分点） | 只搭架子、没给信息、破折号、否定对仗 |
| 估值消化是唯一致命变量 | 估值的下跌幅度超过了盈利的增长幅度 | 贴标签代替讲机制 |
| 利润增长的"确定性"在 2025 年彻底破产 | 原本被认为确定的利润增长，2025 年全面转为下滑 | 情绪词"破产" |
| 茅台上市首次双降、洋河净利 −67%、五粮液会计暴雷、泸州老窖 −20% | 茅台上市以来营收净利首次双降，洋河净利润降 67%，泸州老窖降 20%，五粮液因会计差错更正大幅下滑 | 黑话"暴雷"、电报体堆叠 |
| 人均消费从未"升级"，只是高端化撑了几年 | 人均饮酒量一直在下降，所谓升级只是高端酒提价支撑了几年收入 | 太模糊，没说清"升级"指什么 |

| 关键陷阱：当整个蛋糕在缩，龙头抢到更大份额……份额赢家在一个缩量、杀估值的市场里，股东仍然亏掉一半 | 需要注意：行业总量在萎缩，龙头即使份额上升……在一个总量收缩、估值下降的市场里，份额上升的公司股东仍然亏损约一半 | 比喻连用 |
| 最反直觉的结论：你把基本面基本都赌对了，买在顶点照样亏一半。决定……的，不是行业看得准不准，而是出价贵不贵 | 结论是：即使把基本面判断基本都做对了，买在顶点仍然亏损约一半。对 2021 年的买家来说，决定盈亏的是买入时的估值高低，不是行业判断准不准 | "最反直觉""赌对"、否定对仗 |
| 这恰好是……方法论的真正分野——也是这轮周期给所有"好公司可以不看价格"信仰者上的一课：起点估值，是长期回报里最不可逆的那个变量 | 张坤用 ROE 框架提示要降低收益预期……这轮周期说明：买入时的估值，对长期回报的影响最大，而且事后很难弥补 | 拔高、"信仰者上的一课"、破折号 |
| （标题）好公司，错价格 | （标题）白酒龙头估值复盘 | 口号式标题 |
| 两条都在向上——这是四个假设里最正确的一条 | 两条线都在上升，是四个假设里最成立的一条 | 破折号抖包袱 |
| 白酒龙头彻底不再是同质资产 | 五家龙头的业绩差异已经很大 | 术语腔 |

| 答案很清楚。2026 财年资本开支 1261 亿元，主要去向是 GPU 服务器、数据中心和自研芯片 | 2026 财年资本开支 1261 亿元，主要投向 GPU 服务器、数据中心和自研芯片 | 开场垫话"答案很清楚" |
| 那估值什么时候会修复？触发条件只有一个，不是"阿里改好了"，而是市场看到阿里云从亏损期转向收割期的具体信号 | 估值修复的触发条件：市场看到阿里云从亏损转向盈利的具体信号——例如云业务经营利润转正、资本开支增速回落 | 设问自答 + 为转而转"不是 X 而是 Y" + "收割期"比喻 |
| 搞清这条逻辑线，你才能判断现在的下跌是地基在塌，还是只是工地在挖坑 | 分清这轮下跌是盈利能力结构性恶化，还是阶段性加大投入压低了当期利润——两者对估值的含义相反 | 比喻二选一 + 开场垫话 |
| 最新的两个前沿模型把这件事钉死了。……GPT-5.6 Sol 用约三分之一的成本、更少的 token，打到了几乎同一条能力线上。规模不再是能力的单一解释变量，这是当前最硬的证据 | ……GPT-5.6 Sol 用约三分之一的成本、更少的 token，达到几乎相同的能力水平。规模已经不能单独解释能力差异 | 小段强行总分总：开头"钉死了"甩结论、结尾"最硬的证据"再拔高一遍；"打到能力线上"比喻。数据全留 |
| 预训练单维放大已经走平，scaling 转向后训练和推理时计算 | 过去靠不断堆大参数量提升模型能力，现在这条路收益见顶，重点转向扩大数据和训练后调优（本质：Scaling Law 从堆参数转向堆数据） | 一句塞四个没定义的黑话（单维放大 / 走平 / scaling / scaling 转向……推理时计算），谁不预先懂就读不懂；剥掉黑话意思很简单 |

## 二、词和短语替换总表

### 情绪、暴力、比喻词 → 换成字面

| 改前 | 改后 |
|---|---|
| 估值消化 / 杀估值 | 估值下跌 |
| 单边杀估值吃掉利润增长 | 估值下跌幅度超过利润增长 |
| 会计暴雷 | 因会计差错更正大幅下滑 |
| 也崩了 / 崩盘 | 开始下跌 / 大幅下跌 |
| 近乎清零 | 降 67%（用实际数） |
| 彻底破产（指假设失效） | 全面转为下滑 / 不成立 |
| 蛋糕在缩 | 行业总量在萎缩 |
| 份额赢家 | 份额上升的公司 |
| 护城河救不了股东 | 集中度提升没有给股东带来回报 |
| 最后一根柱子也塌了 | 收入和利润也开始下降 |
| 价盘松动 | 批价下跌 |
| 收割期 / 进入收割 | 盈利期 / 进入盈利 |
| 打到同一条能力线上 | 达到几乎相同的能力水平 |
| 贴身差距 | 只差 1 分（用实际数） |

### 设问、开场垫话 → 删掉，直接给结论

| 改前 | 改后 |
|---|---|
| 那 X 什么时候会 Y？（设问自答开头） | 删设问，直接给结论 |
| 答案很清楚 / 答案是 | 删，直接陈述 |
| 问题来了 / 值得一问的是 | 删 |
| 说到底 / 归根结底 / 本质上 / 说白了 | 删，直接说实质 |
| X 把这件事钉死了 / 一锤定音 / 板上钉钉（开场甩结论） | 删，直接摆事实 |

### 反转金句、比喻二选一 → 落到字面

| 改前 | 改后 |
|---|---|
| 这不是 X，是 Y（反转金句） | 直接讲 Y 是什么 + 机制（"这不是亏损，是预付款"→"计入当期成本，对应未来交付的算力产能"） |
| 是 A 还是 B（A、B 都是比喻） | 写两种字面情况 + 怎么区分（"是地基在塌还是工地在挖坑"→"结构性恶化还是阶段性加大投入"） |
| 不是 X，而是 Y（X 是稻草人） | 删"不是 X"，直接陈述 Y |

### 口号、拔高 → 删掉，或落到事实

这一节针对的是**没有实质内容、只靠句式撑场面**的口号，跟下面「核心句 → 从书面判断句改成能喊出口的」那节不冲突：那节改的是有实质、要被读者复述的核心句，把它从书面语改成能出口的话。分界线在这句背后有没有一个具体动作。

| 改前 | 改后 |
|---|---|
| 最该记住的一条 | 删 |
| 最反直觉的结论 | 结论是 |
| 本报告核心一图 | 下图对比两者走势 |
| 这轮最贵的一课 / 给信仰者上的一课 | 删 |
| 起点估值是最不可逆的那个变量 | 买入时的估值对长期回报影响最大，事后很难弥补 |
| 强者恒强 | 继续上升 |
| 讽刺的是 | 删 |
| 兑现得最干净 | 兑现得最确定 |
| 这是当前最硬的证据 / 这已经说明一切（结尾强行拔高） | 删，让前面的事实自己说话 |

### 否定排比、对仗 → 拉平

| 改前 | 改后 |
|---|---|
| 决定回报的是出价贵不贵，而非基本面对不对 | 决定盈亏的是买入时的估值高低，不是行业判断准不准 |
| 基本面向上、估值向下、股价净跌（三段对仗） | 利润上升、估值下降，两者相抵后股价净跌 |
| 集中度提升 ≠ 股东赚钱 | 集中度提升并没有让股东赚钱 |

### 伪框架、标签式概括 → 删掉或填实

| 改前 | 改后 |
|---|---|
| 四个看多支柱里三个大体兑现……（只搭架子） | 删掉，改成直接列四个问题的结论 |
| 分化为三派：死守派 / 反思派 / 反复派 | 直接写每个人怎么做（刘彦春满仓、焦巍清仓后回补、张坤萧楠反复） |
| 预训练单维放大已经走平，scaling 转向后训练和推理时计算（黑话浓缩当洞见） | 剥成大白话：过去靠堆参数量提升能力，现在收益见顶，转向扩大数据和训练后调优。术语要么讲清、要么第一次定义 |

### 生造组合词、内部工程黑话 → 拆成动作

| 改前 | 改后 | 毛病 |
|---|---|---|
| 估值章接法 | 估值章节数据接入 | "接法"没有说明接入什么数据、写到哪里 |
| 软依赖：没模型就先触发跑 | 模型准备：模型不存在时先生成估值模型 | "软依赖"和"触发跑"是内部工程话 |
| 模型交付门 | 模型校验：完成重新计算和验证后才能写入报告 | "门"是比喻,隐藏了校验动作和通过条件 |
| 物理锚链叙述 | 业务驱动分析：说明出货量、单价等指标如何影响收入、利润和估值 | 名词连续堆叠,没有写具体指标和传导关系 |
| 多镜头三角验证 | 估值方法对照：至少使用两种估值方法交叉核对 | "镜头"和"三角"都是装饰比喻 |
| 隐含价阶梯 | 逐年隐含价 | 用形状比喻表格结构 |
| 历史底座 | 历史数据 | "底座"没有增加信息 |
| 镜头体检 | 估值结果核对 | 两个比喻叠在一起 |
| 情景翻档 | 切换情景或调整参数 | 把参数变化写成机械动作 |
| 链断 | 上下游公式不再联动 | 只报标签,没有说明故障表现 |
| 公司切片 | 公司在相关市场中的收入和份额 | 内部建模术语直接暴露给读者 |
| 收入挂在 capex 上 | 收入由 capex 和收入强度共同决定 | "挂"掩盖了公式关系 |
| 把结果喂给估值表 | 估值表引用该结果 | "喂给"是口语化工程黑话 |

| 改前 | 改后 |
|---|---|
| 两家的分野不在赛道，在场景 | 两家在同一条赛道上，差别出在选了哪个场景 |
| 战略分化不是理念分歧，是禀赋函数 | 每家公司押的那个核心变量，是被自身的资源结构逼出来的 |
| 现金流能自造血 | 现金流靠自身收入覆盖支出 |
| 决定了崩盘时谁还在牌桌上 | 决定了崩盘时哪些公司还活着 |
| 进入正向飞轮 | 下一代模型的能力提升速度会因此加快 |
| 名义敞口约 500 亿美元 | 这些期权挂钩的股票市值约 500 亿美元 |
| 靠外部输血维持的模式立刻停摆 | 靠外部融资维持的模式立刻停止运转 |

### 论证记账 → 删掉，或换成实质论证

主语是文章自己（这一组、这张表、上面三个动作），谓语是论证动作（打掉、合起来看、浮出来），就是这一类。读者读完一个新信息都没有。

| 改前 | 改后 |
|---|---|
| 把两组数字放在一起，结论自己浮出来：靠烧钱买来的用户没有留存 | 靠烧钱买来的用户没有留存（删掉前半句，信息不减） |
| 这张表的读法有三条，比表本身重要： | 直接写这三条各自是什么（元话加自夸，整句删） |
| 这一组两个案例……它们分别打掉上面三个动作里的两个 | 估值、增长、创始人这三样，下面两家公司当年全都有，而且比今天绝大多数 AI 公司更硬：一家融了 4.5 亿美元、股东名单上有微软和软银，一家是 Google 之后美国最大的一次互联网公司上市。它们最后的结局，跟这三样都没有关系 |
| 这一组把"选回报最高的那一种"这个动作打掉了。适合孙正义的东西不一定适合你，区别不在眼光，在你能不能承受连续几次归零 | 孙正义这两笔的差别不在眼光。2000 年他看懂了中国电商，2019 年他看错了共享办公，一对一错，这个命中率放在风险投资里不算差。差别在于投错 WeWork 那 100 亿之后，软银第二天照常开门；换成一个个人投资者，连着错三次就没有第四次了 |
| 回看 1.2 那一组：Sandberg 做的正是"跟偶像合伙" | Sandberg 跟偶像合伙那一组：…… （引用写事情的名字，不写编号） |
| 这一节和第一单元的关系：岗位思维要求的能力…… | 直接写岗位思维要求的能力是什么 |

### 标题里的指代和比喻 → 换成它指的东西

标题排在正文前面，读者读到时还没读正文，所以"正文里定义过"不算数。

| 改前 | 改后 | 毛病 |
|---|---|---|
| 导入　名单已经在你手上了，你怎么接上去 | 导入　判断出哪几家公司会赢，和从它们身上赚到钱 | 什么名单、什么叫接上去，三处都不知道 |
| 1.2 这三个动作为什么活不过崩盘 | 1.2 不挑场景、挑用户最多的、跟着热度切，这三种做法撑不过一个行业周期 | 读者还没读到 1.1，不知道哪三个 |
| 2.3 照妖镜之一：Kimi 与 DeepSeek | 2.3 第一种假象：买量买来的用户 | "照妖镜"是比喻，"之一"不知是几个里的一个 |
| 2.2 一次已经兑现的错误定价 | 2.2 2025 年市场对谷歌的一次错误定价 | 哪一次、谁的 |
| 2.3 范本：四层齐备是什么样子 | 2.3 范本：芯片、操作系统、大模型、分发，四层齐备是什么样子 | 哪四层 |
| 收场　把照妖镜带回去 | 收场　三种假象，回去逐个筛一遍 | 比喻 |

"崩盘"在正文里特指某一次泡沫破裂，标题里当泛指的时间点用就过窄，换成"一个行业周期"；正文里有定义，保留不动。

### 量词化比喻和单字动词 → 直接说标准和动作

| 改前 | 改后 | 毛病 |
|---|---|---|
| 量赛道和量时机，两把尺子带回去 | 两个标准：选赛道，选时机 | "尺子"是空容器（怎么量、什么刻度、多少算过关都没说）；"量"没人这么搭；"带回去"是口播套话 |
| 三把尺子量下来，这家公司只过了一把 | 三条标准里这家公司只满足一条：收入增长达标，毛利率和留存都不达标 | 同上，且"只过了一把"没说没过的是哪两条 |
| 给你三个抓手 | 三件具体要做的事：…… | "抓手"是容器名词 |
| 这是判断的一面镜子 | 用这个数据可以反过来验证前面的判断 | "镜子"删掉信息不减 |

容器名词清单：尺子、镜子、抓手、钥匙、柱子、锦囊、法宝、罗盘、照妖镜。单字动词清单：量、锚、卡、破、立、拆——问一句"日常中文里有人这么搭配吗"。

### 无实体比喻 → 先问那东西存不存在

| 改前 | 改后 |
|---|---|
| Builder.ai 坏在收入那一行是假的，Groupon 坏在收入那一行是真的、下面几行是负的 | Builder.ai 的营收数字本身是伪造的：对外宣称 2024 年营收 2.2 亿美元，实际约 5500 万美元。Groupon 的营收数字是真的，用户确实在买券，商户确实在付佣金，它失败的地方在收入之外：地推团队的人力成本，加上拉新用户的折扣补贴，两项之和超过了收到的佣金，而且签的商户越多，这个缺口越大 |
| 要提前看见，得往下翻：翻到获客成本、留存率、边际毛利和月度现金消耗这四行 | 要在事情发生之前判断出来，得另外查四个数字：获客成本、留存率、边际毛利、月度净现金消耗。查这四个，是因为它们分别回答四个问题：用户是买来的还是自己来的，来了之后留不留得住，每多服务一个人是赚还是亏，账上的钱按现在的速度还能撑几个月 |
| 分辨的位置不在营收那一行，在营收下面那几行 | 不能只看它收进来多少钱，还要看为了收进这笔钱，它花掉了多少 |
| 这张表里最该盯住的是最后三行 | 表里后三项是同一笔钱的三种结局 |

上下文里真有那张表时（"找到你所在的那一列，圈出你实际所在的那一行"），是操作指令，照留。

### 评价词 → 换成数字和事实

| 改前 | 改后 |

### 核心句 → 从书面判断句改成能喊出口的

只用于教材、课程、口播、演讲这类有"要被复述的一句话"的文本。判别：用嘴巴思考，不要用眼睛思考。

| 改前（写在纸上好看） | 改后（喊得出口） | 原句错在哪 |
|---|---|---|
| 十年万亿才配研究，崩盘那天才配出手 | 不到万亿别看，不见崩盘别买 | "才配"是评判语气，听完不知道要干什么；"别"是动作 |
| 场景跑不出经济模型，用户过亿也是虚的 | 不看谁在用，只看谁付钱 | "经济模型"是黑话，喊不出口 |
| 四条闭环全过，才配进前十名 | 断了融资还能活，才配进前十 | 拿数字当钉子——四条是哪四条，记不住 |
| 选错打法，比选错公司更贵 | 不选最厉害的，只选最像你的 | 陈述句只讲代价不讲动作 |
| 本金的期限，必须等于判断的期限 | 钱放得住多久，判断就做多久 | 像法条；改成回环，六字对六字 |
| 先定几号位，再把长板做到极致 | 先认清几号位，再把长板使到头 | "做到极致"是书面语（"长板"是日常话，留） |

## 三、对冲词清单

有两种"对冲"，一种该删，一种该留，分清楚。

**堆砌型对冲词，一句最多留一个，多了就删。** 这类是对观点心虚：可能、或许、也许、大概、似乎、貌似、在某种程度上、一定程度上、某种意义上、被认为、据称、据说、相对而言、总体而言、整体来看。

想表达不确定，用一个明确的词就够，别叠起来写成"该政策或许在某种程度上可能被认为产生某些影响"。

**数据估算时的对冲该留，那是标口径，不是含糊。** 约、左右、近、超过、不足、~ 这些是诚实地标注估算精度。"约 7366 亿""~20 倍""近 74%""基本持平"都属于这一类，照写。

区别就在这：对冲观点是心虚，对冲数据精度是严谨。
