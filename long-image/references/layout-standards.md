# 内容与版式标准

## 结构

- 单条深色竖线贯穿内容，一级章节标签以浅色块直接压在竖线上，观点条与表格由短横线接入竖线。
- 不得将章节标签另开为左侧栏，也不得将正文改成 `01/02` 文章式编号版。
- 顶部标题属于页面主标题，必须从完整内容宽度起排；不得随着竖线正文列缩进。

## 标签与观点条

- 左侧标签只放精炼章节名；完整逻辑由右侧观点条表达。
- 优先使用 6-12 个汉字的 `section.tag`，过长标题必须压缩后再放入标签。
- 每张观点条都必须通过横线连接至竖线。
- 保持扁平、紧凑、无厚重阴影的风格。

## 配色

- 相邻一级章节不得使用同一 `tone`。即使输入 JSON 连续指定同色，渲染器也会自动切换为下一种协调色。
- Internal 与 External 分别按实际可见章节重新计算。

## 尺寸与间距

- 导出宽度固定为 1080px，高度由内容决定。
- 9:16 仅用于首屏预览，不是内容边界。
- 顶部保留 132px 安全区；左右各 72px。
- 正文与底栏之间保留 70px 白色间隔。
- 底部使用 1080x400px 品牌栏，总占用（间隔 + 品牌栏）严格为 470px，不得额外追加纯色安全区。

## 字号

1080px 导出下：
- 顶部标题：约 52px
- 观点条正文：约 27px
- 左侧标签：约 26px
- 正文下限：不得小于 22px

每条观点尽量控制在 2-4 行。超过时拆分、合并或缩短，不要靠压小字号容纳。

## 表格

- 表格是线图的一部分：置于观点条下方，仍通过横线接入竖向主线。
- 优先用于原 reference 中本就存在的关键对照表，避免把所有正文机械表格化。
- 最多 4 列；1080px 导出下表内文字不小于 19px。
- 优先使用 2-3 列以保证手机阅读。

## 底栏与品牌

- 默认使用"完整研报加入智富界交流群"、平台介绍和"扫码获取完整研报"二维码。
- 顶部二维码栏略小于底部二维码栏，二者均使用同一二维码。
- 底栏以独立背景、活字和二维码分层渲染，不得把文字或二维码固化进背景图片。
- 品牌资产和文案默认从 `assets/brand.json` 读取，优先于输入 JSON。
- 直接覆盖 `assets/zhifujie-qr.png` 即可替换两处二维码。
