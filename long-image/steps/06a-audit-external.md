# 步骤 6a：External 成品终审（Sub-agent）

仅 `dual` 模式执行。在自动化验收通过后，启动一个 sub-agent 对 External 成品做最终合规审查。

## Sub-agent 职责

将以下内容交给 sub-agent：
- External HTML 文件的纯文本内容（去除 HTML 标签和 CSS）
- `references/external-compliance.md`

要求 sub-agent 以"合规审阅员"视角逐段阅读，重点关注正则词表覆盖不到的隐晦表述：

1. **暗示性投资建议**：如"空间显著""赔率合适""配置价值凸显""左侧布局时点"等非标准但具有投资引导性质的措辞。
2. **残留的前瞻性判断**：如"有望突破""预计将""大概率"修饰具体标的表现的表述。
3. **上下文泄漏**：单句无敏感词，但结合上下文能推导出投资结论的段落。
4. **标题与正文一致性**：External 标题是否暗示了内部版才有的投资方向。

Sub-agent 对每条发现给出：位置（章节/卡片）、原文引用、风险说明。

## 主 agent 处理方式

Sub-agent 的输出是建议清单，不是最终裁决。主 agent 逐条审阅：

- **认同的**：回到步骤 3 修改 JSON，重新渲染和验收。
- **不认同的**：忽略，无需解释原因。
- **不确定的**：向用户说明 sub-agent 的发现和原文，由用户决定。

全部处理完毕后，交付最终成图。
