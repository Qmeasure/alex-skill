# 报告模板与版式

这份文件规定最终 DOCX 的信息编排：首页、Key data 页、图表编号、章节骨架。版式机制（配色色值、字号行距、双栏 DXA 宽度、正文窄栏、页眉页脚构造）由 `../references/Word文档格式标准.md` 管，那份为准，这里不重复列数值。组装报告（阶段 5）前两份都要读。

版式对标外资投行研报的首页结构（左摘要 + 右投资数据栏），正文按中式投资逻辑链组织。

## 首页

首页分三区，从上到下：品牌横幅 → 标题区 → 双栏区。页底不放表：盈利预测及估值摘要表在第 2 页。

### 一区：品牌横幅

左 logo + 深蓝「智富界」，同行右端「首次覆盖研究」+ 报告日期，下方亮蓝粗线。构造细节见格式标准的「机构标识」节。

### 二区：标题区

1. **主标题**。一句带判断的话，不是中性描述：「守正创新，基业长青」「国产 AI 芯片领军者，云边端共铸核心壁垒」这类。大字加粗黑，独占一行或两行。
2. **副标题**。补充主标题的具体判断，灰色，字号小一档。比如主标题讲地位，副标题就讲支撑地位的那个变量和时间表。
3. **股票标识**。公司全称 + 代码（拼多多 PDD.O / 腾讯控股 00700.HK / 寒武纪 688256.SH），加行业归类（电商 / 社交Ⅱ / 集成电路）。

### 三区：双栏区

左栏（68%）放报告摘要，右栏（28%）放投资数据块。

**左栏，报告摘要**。全文最浓缩的版本，也是首页的主体，**要写满左栏版面**。**不单独写引言**，开头用一句点题设问或钩子领起（这家公司最值得研究的那个问题），随后按「一 / 二 / 三 + 投资建议 + 风险提示」分层，每层用一句加粗判断领起，再展开 3–4 行给出机制和数字。层次结构对应正文逻辑链：概况 / 空间 / 驱动，最后落到投资建议和风险提示。摘要之后正文直接从「一、公司概况」起，没有独立引言段。

首页页底不放盈利预测及估值摘要表（那张表在第 2 页），左栏因此有充足版面。摘要写短了首页下半会空一大块，那是内容不足，不是留白设计。

**投资建议层和风险提示层各带一句固定的 AI 声明，文案写死，不逐份改写：**

- 投资建议层的加粗领起句固定为「**投资建议（AI 生成）：**首次覆盖给予 [评级] 评级，目标价 [币种+数值]。」
- 风险提示层的最后一句固定为「本报告的预测、评级和目标价均由 AI 研究团队生成，未经人工分析师复核。」

风险提示层给最重的 4–6 条，每条带机制不只给名词；完整的 8–12 条留在正文 4.3，不另设第三处。

**右栏：投资数据块**。顺序固定，十个元素一个都不能少、不能换位。**标签与数值统一 8pt 常规、两侧同字号、都不加粗**，层级只靠颜色（细则见 `../references/Word文档格式标准.md` 的「首页双栏」节）：

| # | 元素 | 说明 |
|---|------|------|
| — | **右栏左侧竖线** | 深蓝 `#1B3A6B` 细线，贯穿整个右栏，把投资数据区与左侧摘要分开。全文唯一的竖线 |
| 0 | **「AI 投资建议」区块标签** | 8pt 加粗亮蓝，下方亮蓝细线。压在评级 / 目标价 / 当前价 / 上行空间这四项之上，标明它们是 AI 生成的投资结论；总市值与日均成交属市场数据，用浅灰细线与之分开 |

## Pre-IPO / 拟上市标的分支

标的尚未上市时（已申报、已过会、待发行），首页右栏的十个元素里有五个不存在：当前价、上行空间、总市值、日均成交、相对表现图。评级也不能用二级市场的档位。走这一支。

**右栏元素**（顺序同样固定）：

| # | 元素 | 说明 |
|---|------|------|
| 0 | 「AI 投资建议」标签 | 同已上市版，8pt 加粗亮蓝 + 下方细线 |
| 1 | 申购建议 | **积极参与 / 谨慎参与 / 观望**三档。不得使用买入、增持、中性这类二级市场评级档，标的还没有二级市场价格，给评级没有参照物 |
| 2 | 合理市值区间 | 发行后总市值区间，**代替目标价**。亮蓝 |
| 3 | 对应发行后 PE | 合理市值 ÷ 最近完整年度归母净利，标明用的是哪一年 |
| 4 | 拟募资额 | 招股书披露值 |
| — | 浅灰细线 | 以下为客观数据，不是 AI 判断 |
| 5 | 拟发行股数 / 发行后总股本 | 招股书披露值 |
| 6 | 上市板块与审核进度 | 如「科创板 · 已过会 2026-06-01」 |
| 7 | 最近一轮投后估值 | 带轮次与时点 |
| 8 | 三年营收与净利迷你图 | **代替相对表现图**（未上市没有行情序列），宽度同样取满右栏约 4.7 cm |
| 9 | 亮蓝分隔线 + AI 研究团队块 | 同已上市版，含二维码与「扫码加入社群」 |

**其余差异**：

- **招股书是唯一一手源。** 财经媒体的拆解稿常与招股书正文对不上（申报稿与上会稿之间数字会更新），二手报道与招股书冲突时一律以招股书为准，并在 `_data` 底稿记录冲突的两个值、各自出处和采信理由。
- **估值不给目标价**，给发行后合理市值区间，方法是可比上市公司 PE / PS 乘以最近完整年度的净利或营收，并说明可比公司的选取理由与不可比点。
- **Key data 页**的「基本状况」改为「发行方案与股权结构」：拟发行股数、发行后总股本、募资额与募投项目分配、实控人及持股比例、主要机构股东。
- **两处 AI 声明按本分支的口径改写**（已上市版提的「评级和目标价」在这里不存在，照抄会自相矛盾）：
  - 投资建议层领起句：「**投资建议（AI 生成）：**给予 [申购建议]，合理市值区间 [下限]–[上限] 亿元。」
  - 风险提示层末句：「本报告的预测、申购建议和合理市值区间均由 AI 研究团队生成，未经人工分析师复核。」
- 风险提示要额外覆盖上市进程本身：发行失败或延期、发行价高于合理区间、限售解禁、上市后无可比交易数据。

## 第 2 页：Key data

整页数据，不写论述文字，**四块内容全部收在这一页**。字号 7.5pt、单元格上下边距 30 DXA。

**上半：公司盈利预测及估值摘要表**，占满 18.6 cm 版心。横轴是年份（含 A/E 标识），纵轴是关键指标：

| 指标 | 2024A | 2025A | 2026E | 2027E | 2028E |
|------|-------|-------|-------|-------|-------|
| 营业总收入 | | | | | |
| 收入 yoy% | | | | | |
| 归母净利润（非 GAAP 或经调整） | | | | | |
| 非 GAAP 净利 yoy% | | | | | |
| 每股收益（本币 / ADS） | | | | | |
| 每股收益（交易币种） | | | | | |
| PE | | | | | |

年份列数按数据可得性定：非 GAAP 口径的历史年拿不到就从拿得到的那年起列，不留 `未获取` 占位在封面级表格里。口径小字放表内跨列末行。

**下半：无边框二列表格，每栏 9.3 cm**

- 左栏：基本状况（总股本、流通股本、市价、总市值、52 周高低、汇率等）+ 现金流量表与资产负债表摘要
- 右栏：利润表摘要（分部收入、成本、毛利、毛利率、经营利润、归母净利润，历史年 + 最新季度）

三张表的口径、币种、财年截止必须与阶段 2 模型完全一致。

第 3 页起进正文「一、公司概况」。

## 合规样板

首页和全文都不放执业编号、评级体系图例、法律免责声明，这些是合规填充，本 Skill 一律省略。评级、目标价、风险提示要保留，它们是分析结论。

## 图表编号与来源脚注

中文研报把图和表统一编号，叫「图表 N」，全文连续不断号（图表 1、图表 2、图表 3……不分图和表两套号）。深度报告通常 40–70 个。阶段 4 的 PNG 使用稳定资产 ID、不预占编号；阶段 5 把原生 Word 表格和图片全部排定后，再按正文顺序统一编号。首页和 Key data 页的表不进入「图表 N」序列。

每个图表的规范：

- **标题在上**：「图表 N：[描述性标题]」，比如「图表 11：拼多多分业务营业收入（亿元）」。标题带单位。
- **来源在下**：小字，「来源：公司公告、SEC EDGAR、智富界 AI 研究团队」。
- 只保留页码内容目录，不另做图表目录（list of figures）。

## 正文章节骨架

正文按中式投资逻辑链组织，不按固定清单。骨架是这套，具体章名按公司和行业起，**给结论、带数字，不用比喻**（见 `研报写作规范.md`）：

```
一、公司概况：[一句判断式标题]
  1.1 历史复盘——沿革、关键节点、股价复盘
  1.2 业务布局——分部拆分、变现模式、股权与治理、管理层
  1.3 财务分析——历史收入/利润/现金流/回报的趋势

二、行业空间：[一句判断式标题]
  2.x 市场规模、增长驱动、政策、产业链位置
  （可按业务分部分别讲空间，如 2C / 2B）
  章末从 Excel 的产业链主题 sheet 摘取精简表，并写清产业链利润池、跨环节定价和传导变量的结论；完整视图留在 Excel

三、核心驱动 / 竞争壁垒：[一句判断式标题]
  3.x 支撑投资逻辑的关键变量——技术壁垒、生态、新业务、AI 等
  从 Excel 的经营对标 sheet 摘取关键字段，写清相对竞品的经营强弱、优势机制、短板及盈利影响
  这是全文最重的一章，回答"凭什么是它、凭什么是现在"

四、盈利预测与估值
  4.1 盈利预测——分部收入预测 + 利润预测 + 关键假设
  4.2 估值分析——从 Excel 的估值可比 sheet 摘取关键估值列和分位，写清溢折价、目标倍数依据和估值组迁移变量 + SOTP + DCF 辅证 + 目标价 + 评级 + 足球场图
  4.3 风险提示——8–12 条，分类列

附：盈利预测三表摘要（可选）
```

章节顺序可随公司调整（比如把「竞争壁垒」放在行业之后、盈利预测之前），但逻辑链的走向不变：先认识公司，再看行业给了多大空间，再论证它凭什么吃下这个空间，最后落到能赚多少、值多少、风险在哪。每一章都在推进投资论点，不是各自独立的资料堆砌。

骨架里 1.1 / 4.1 这种子项名只是结构占位，**落到报告里的小标题要带判断，不要停在中性名词**（详见 `研报写作规范.md` 的「章节标题」节）。比如「投入端：capex 总量与节奏」这种中性标题，改成「capex 的 78% 集中在四家超大厂」这类带数字带判断的。大标题小标题一视同仁。

带判断不等于带比喻。「广告平台的外壳里长出了一家履约公司」「站在利润池最厚的一段」这类标题读者第一眼看不懂在说什么，是最典型的 AI 味来源，想让标题「有画面」，结果画面盖住了信息。标题的唯一任务是让读者知道这一节的结论。

## 版面

字体、字号、行距、页边距、配色色值、正文窄栏、双栏宽度、表格、图注这些排版数值，统一以 `../references/Word文档格式标准.md` 为准，这里不另列一套。本文件只管研报特有的部分：

- **图表配色**：全报告一套四色板，深藏青 `#1F3A6E` 主系列 + 珊瑚红 `#E15759` 次系列/强调/负值 + 中蓝 `#76A9E8` 第三系列 + 灰 `#9AA5B1` 辅助。柱用深藏青、线用珊瑚红，一冷一暖才拉得开；珊瑚红在同一张图里只承担一个角色。图表配色独立于 Word 文字配色，不共用色值。细则见 `../references/阶段4-图表生成.md`。
- **版面密度**：正文 60–80% 版面有内容（图文表混排，不要大片留白），尽量每页都有图或表。避免「一页就一张图」或「标题下面没正文」。图配文、表配解读。
- **图和表必须占满宽度**：单张图或表铺满 18.6 cm 版心，成对的拼一行各占 9.3 cm。缩小后孤零零居中在页面中间是禁止项。成对/可对照的图（分部增速对比、可比公司倍数、三情景、毛利率 vs 净利率等）优先拼一行；两张原生表格同样可以拼一行。
- **横向比较表与结论**：三组横向比较的完整视图和公式放在配套 Excel，DOCX 只摘取支撑正文判断的关键字段，但三组最终投资结论必须进入 Word（落文用读者语言：经营对标公司 / 可比公司 / 产业链公司，不写 O/V/T 代号）。摘取后的表使用原生 Word 表格，不做成图片；宽表按「经营」「规模与盈利」「增长与估值」拆表，保持公司顺序一致，不缩小字号直接填入。目标公司行用浅蓝底 `#F2F6FC` 或加粗高亮，表头/表下注明行情日、财务期间、币种、FX 日期和 `N/M` 口径。每组结论至少有一条数字或图表证据，并落到盈利预测、目标价、评级或风险。

## 体量门槛

- 25–45 页
- 1.5–3 万字中文正文
- 40–70 个图表全部嵌入（不是附在文件夹里）
- 关键财务表 8–15 张

达不到这些，说明内容没有充分展开，补充完善后再交付。用户明确限定范围（比如只要版式验证样张）时按用户范围执行，并说明未达完整体量的原因。
