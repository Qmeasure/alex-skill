# 去 AI 味案例库

这是 `研报写作规范.md` 的配套例子，全部来自真实改稿。写完一段拿不准的话，回来对照着查：左边是改之前的 AI 味写法，右边是改之后落地的写法，最后一列说清楚毛病出在哪。

## 一、整句改写对照

| 改前（AI 味） | 改后（落地） | 毛病 |
|---|---|---|

| 交易服务接棒，利润率触底之年 | 交易服务超过广告，利润率 FY2026 见底 | 「接棒」是比喻 |
| 2.3 利润池集中在平台环节，拼多多站在最厚的一段 | 2.3 平台环节毛利率 56.3%，比自营零售高 40 个百分点 | 「站在最厚的一段」是比喻 |
| 3.3 轻资产结构是真优势，但它保护的是现金流不是短期利润 | 3.3 轻资产结构支撑现金流，但挡不住短期利润下滑 | 否定对仗 + 「保护」拟人 |
| 1.2 季度节奏比年度更能说明问题 | 1.2 广告收入绝对额已停止增长，交易服务连续三季回升 | 自指，评论自己的行文 |

## 三、对冲词清单

研报里有两种"对冲"，一种该删，一种该留，分清楚。

**堆砌型对冲词，一句最多留一个，多了就删。** 这类是对观点心虚：可能、或许、也许、大概、似乎、貌似、在某种程度上、一定程度上、某种意义上、被认为、据称、据说、相对而言、总体而言、整体来看。

想表达不确定，用一个明确的词就够，别叠起来写成"该政策或许在某种程度上可能被认为产生某些影响"。

**数据估算时的对冲该留，那是标口径，不是含糊。** 约、左右、近、超过、不足、~ 这些是诚实地标注估算精度。"约 7366 亿""~20 倍""近 74%""基本持平"都属于这一类，照写。

区别就在这：对冲观点是心虚，对冲数据精度是严谨。
