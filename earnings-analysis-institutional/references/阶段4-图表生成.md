# 阶段 4：图表生成

产物：`[公司]_图表_[日期].zip`，含 18–25 张 PNG（300 DPI）+ 一份图表清单（文件名 + 标题 + 数据来源 + 对应正文章节）。

前置：阶段 1、2、3 产物齐，外部行情数据（12 个月日频收盘、公告前后收盘）能获取。缺失则停下补充。

数据只从阶段 2/3 的 Excel 读取——`预测更新` 出预测修订图，`分部季度序列` 出趋势图，估值 sheet 出估值图；不从阶段 1 Markdown 或旧 PNG 手抄。出图时如发现 Excel 缺数或口径有误，回去更新 Excel 再出图，不在绘图脚本或图表 `_data` 底稿中直接补写新的业务数字。

业绩更新的图表密度低于首次覆盖，但每一张都要指向「这期变了什么」——纯背景图（公司沿革、行业规模、产业链结构）一律不画，那是首次覆盖的内容。图和表统一连续编号。这一阶段把前三阶段的数据可视化，阶段 5 全部嵌入正文。

## 图表数据：只画真值，缺数不补造

图表数据点和正文数字一样，受同一套取数纪律约束——不存在"图表是次要数据可以放水"。这是上一次出事最集中的地方（编造指数线、给基石/解禁/融资图凑假明细、股价图插值补点），这一阶段最该守住。

**每张图建 `_data` 底稿。** 每张图配一份数据底稿，列清每个数据系列的每个点来自哪——`系列 | 数值 | 口径 | 时间点 | 来源`。**底稿里指不到来源的系列，不画**。一张图只有总量真值、没有明细真值，就只画总量，别把它拆成编造的明细图。

**禁止合成、插值、示意填充。** 缺数就留空、标「未获取」，或换一种只用真值的画法，绝不 `np.interp` 补点、`np.random` 加噪声、或贴个"示意/近似"就编一条曲线。"示意/近似/约"只能标真实数据的精度，不能给不存在的数据当免责声明——一个标了"示意"的编造数字，和没标的，对读者危害一样。

**必备图缺数就降级或省略。** 某张必备图的数据不够，降级成只画已知值，或省略并注明"数据未获取"，不补造。少一张真图，好过多一张假图。

**出图后必跑反编造 lint。** 全部图生成后，跑 `scripts/anti_fabrication_lint.py`，把图表构建脚本和各 `_data` 底稿传进去，命中逐条清掉（指到真实来源或删系列）才进阶段 5。脚本只兜机械可检的痕迹（插值、噪声、示意标签、无源系列），看起来合理的错数还得靠异源验证。

## 技术栈

Python + matplotlib + pandas。两件事必须先解决：

**中文字体**（不配置会导致中文显示为方框乱码）。按平台选择可用的中文字体：

```python
import matplotlib
import matplotlib.pyplot as plt
# macOS 优先级：Songti SC / PingFang SC / Arial Unicode MS
# 也可指定思源宋体/黑体的 ttf 路径
matplotlib.rcParams['font.sans-serif'] = ['Songti SC', 'PingFang SC', 'Arial Unicode MS', 'Heiti SC']
matplotlib.rcParams['axes.unicode_minus'] = False  # 负号正常显示
```

生成第一张图后**务必查看一次**，确认中文不是方框，再批量生成。

**研报配色**。图表用独立的四色板，不与 Word 文字配色共用色值：

```python
PALETTE = ['#1F3A6E',   # 深藏青：主数据系列（柱状、目标公司）
           '#E15759',   # 珊瑚红：次数据系列（折线）/ 强调 / 负值
           '#76A9E8',   # 中蓝：第三系列（堆叠第二层、并列第二组柱）
           '#9AA5B1']   # 灰：基准线、辅助线、参考横线
```

四条约束：

1. **柱用深藏青，线用珊瑚红。** 柱线组合图的两个系列必须一冷一暖——同色系（亮蓝柱 + 深蓝线、亮蓝柱 + 黑线）在双图并列的小尺寸和黑白打印下会糊成一片，这是踩过两次的坑。
2. **珊瑚红同时是次系列、强调色和负值色，但同一张图里只能承担其中一个角色。** 实际不冲突：柱线组合图里它是折线，纯柱图里它是负值柱或高亮柱，两类图不重叠。一张图里既有红线又有红柱，读者就分不出红代表什么了。
3. **堆叠柱和并列柱用深藏青 + 中蓝**（同冷色系但明度差足够），不动珊瑚红——那两种图里珊瑚红要留给负值和高亮。
4. 四色不够用时（多分部堆叠、五家以上可比公司），用深藏青的明度阶梯（`#1F3A6E` → `#76A9E8` → `#B9CDE8`）分层，不引第五个色相。

旧色板一律不得再出现：红系 `#C0202E`、`#1F4E79`、亮蓝 `#2B6EF2` 作柱、黑 `#1A1A1A` 作线。亮蓝 `#2B6EF2` 和深蓝 `#1B3A6B` 继续用于 Word 文字与表头，不用于图表数据系列。

## 图表规范

每张图：

- **标题**只写「[描述] [单位]」，用读者语言，不出现 `beat`/`miss`/`seg_A`/`cons` 这类工作代号。图内不预写最终“图表 N”。阶段 5 在原生 Word 表格和图片全部排定后统一连续编号
- **来源**小字脚注「来源：公司公告、WIND、XX研究所」
- 300 DPI（`dpi=300`）。**尺寸按最终占位反推，图在 Word 里要占满宽度、不许缩小后居中**：全宽图 `figsize` 宽 **7.33 in**（18.6 cm @300dpi = 2197 px），双图并列的窄版宽 **3.66 in**（9.3 cm = 1098 px）
- 文件名使用稳定资产 ID + 描述，如 `peer_v_growth_valuation.png`、`chart_segment_revenue.png`；图表清单另列建议插入顺序。不要把阶段 4 的临时顺序当最终编号
- 数据标签清晰，不重叠、不超出边界、不裁切；坐标轴有单位

### 坐标轴与边框

直角坐标图（柱状图、折线图、面积图、散点图）统一去掉上、右边框线，保留 X / Y 实线；所有图一律不画网格线：

```python
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.spines['left'].set_visible(True)     # X / Y 实线保留
ax.spines['bottom'].set_visible(True)
ax.grid(False)                          # 全部图去网格线
```

上边线和右边线永远不要显示。饼图、雷达图、热力图、足球场图、瀑布图没有常规直角坐标轴，按各自惯例处理，不强套这条。

### 双 Y 轴（股价走势对比图）

个股股价和指数点位量纲差几十倍，放同一条 Y 轴个股线会被压平。用 `twinx()` 双轴，两条线都画绝对值、**都用日频逐日收盘**：

```python
import pandas as pd
# 个股、指数都从结算日 K 原始序列读（已落 _data 底稿），不插值、不重采样补点
stock = pd.read_csv('[公司]_daily_close.csv')   # 逐日收盘，结算口径
index = pd.read_csv('[指数]_daily_close.csv')   # 同区间逐日收盘
fig, ax = plt.subplots()
ax.plot(stock.date, stock.close, color=PALETTE[0], label='个股股价（元）')   # 左轴：个股绝对股价
ax2 = ax.twinx()
ax2.plot(index.date, index.close, color=PALETTE[3], label='指数（点）')      # 右轴：指数绝对点位
ax.set_ylabel('股价（元）'); ax2.set_ylabel('指数（点）')
# 左右轴各自图例，或合并图例；ax2 同样去掉 top spine
ax2.spines['top'].set_visible(False)
```

上面这段双轴写法只在正文确实要做个股与指数对照时才用；业绩更新的首页股价图只画个股一条线（见下）。无论哪种，**数据必须是日频逐日真实收盘**——落 `_data` 底稿，按真实日频点画线。不要周频重采样、更不要插值补点。

### 右栏窄版 12 个月股价图（首页必备）

首页右栏那张股价图是独立资产，不是全宽图缩小版。它要在 4.7 cm 宽的栏里读得清，必须单独生成：

- 输出宽度按 4.7 cm @ 300 DPI（`figsize=(1.85, 1.33)`，约 555×399 px），Word 里**按 4.7 cm 摆放占满右栏**，不要缩到 3 cm 以下——缩小后刻度看不清，且与右栏其他元素左右边界对不齐
- **只画个股一条线，不叠指数**。业绩更新看的是绝对价位和 52 周位置——这期业绩落在什么价格水平上、离高点多远，不是跑赢跑输指数多少
- **原始收盘价，不归一化、不重设起点为 100**，近 12 个月，**日频逐日真实收盘**，不插值、不重采样
- 线用深藏青 `#1F3A6E`
- **图内标最新价与 52 周高低**：最新价标在线的末端，52 周高低用两条灰 `#9AA5B1` 虚线加右侧数值；公告日可加一个珊瑚红竖向标记
- 窄图里字要能看清：刻度字号 5–6pt，X 轴只保留 4–5 个月份刻度，Y 轴刻度 3 个，去掉轴标签文字（栏太窄放不下，口径写在图下小字）
- 无网格线、无上/右边线，与其他图一致

正文里如果还要一张公告前后股价反应图，两张数据同源、口径一致，不各取一份序列。

### 双图并列尺寸

成对/可对照的图（本期 vs 去年同期、旧预测 vs 新预测、毛利率 vs 费用率、新指引 vs 旧指引等）在阶段 5 会一行两图并列，**每张占满半栏 9.3 cm**。这类图按窄版生成：`figsize=(3.66, 2.7)` 左右、长宽比偏 4:3、字号适当放大，让它在 9.3 cm 下仍然清楚。单张图按全宽版 `figsize=(7.33, …)` 生成。

**两种尺寸都必须在 Word 里占满各自的位置**——生成时就按最终宽度定 `figsize`，不要生成一个尺寸再靠 Word 缩放去适配，那样要么模糊要么缩成孤立的小图。阶段 5 用无边框二列表格放置（见 `Word文档格式标准.md`）。

## 业绩更新的固定配色用法

四色板之上，业绩更新多一条全文一致的约定：

**超预期用深藏青 `#1F3A6E`，低于预期用珊瑚红 `#E15759`。** 差异柱、瀑布图的增减段、预测上调下调，全部按这个规则上色，读者扫一眼颜色就知道方向，不用读标签。这条覆盖「珊瑚红作负值」的默认用法——在业绩更新里，负值和低于预期本来就是同一件事。

中蓝 `#76A9E8` 留给「本报告此前预测」和「一致预期」这类参照系列，灰 `#9AA5B1` 留给去年同期的基准线。

### 一、业绩总览（3–5 张）
