# 阶段 5：报告组装

产物：`[公司]_[季度]_业绩更新_[日期].docx`，14–18 页、6,000–9,000 字、18–25 个图表全部嵌入。全流程交付时同时保留阶段 2/3 的联动 Excel。

前置：阶段 1、2、3、4 产物全部齐备且达标。缺任何一个就停下，列出缺口。

开始前必须读完三份：内嵌 DOCX Skill `../anthropic_skills/docx/SKILL.md`、`Word文档格式标准.md`、`../assets/报告模板与版式.md`。写正文时手边放着 `../assets/研报写作规范.md`。

## 数字来源

所有数字从阶段 2/3 的 Excel 和阶段 1 的 `_data` 底稿取，**不在这一阶段重新检索、重算或手录**。发现数字有误，回上游改 Excel 或底稿，再重新生成下游产物——不要只改 DOCX 里的那一处，那会造成跨文件不一致。

## 首页

按 `../assets/报告模板与版式.md` 的「首页」节做。三区：品牌横幅 → 标题区 → 双栏区。

三件最容易做错的：

1. **右栏元素顺序固定**，「AI 投资建议」标签压在评级/目标价/当前价/上行空间之上，浅灰细线以下才是客观数据（报告期、收入 vs 一致预期、EPS vs 一致预期、总市值、12 个月股价图）。
2. **右栏第 9 项是原始收盘价的 12 个月股价图**，不是首次覆盖版那张相对表现图。业绩更新的读者关心绝对价位和 52 周位置。
3. **摘要第一句直接给业绩结论加幅度**，不写背景铺垫。摘要要写满左栏版面。

内层表宽必须由外层单元格的实际边距推导（见 `Word文档格式标准.md` 的「首页双栏」节），不要另写一个数字——两处对不上会把整块内容顶出版心。

## 第 2 页：业绩速览

三块内容全部收在一页，字号 7.5pt、单元格上下边距 30 DXA：上半全宽三口径对照表，下半左分部拆分、下半右指引对照 + 预测更新摘要。不写论述文字。

首页和这一页的表不进入「图表 N」序列。

## 正文各章怎么写

### 一、业绩总览

**1.1 三口径对照与差异归因。** 从第 2 页那张表里挑最重要的三到五行展开——不要把整张表再讲一遍，读者刚看过。每一项偏离都要回答：差多少、差在哪个分部或科目、一次性还是可持续。配差异条形图和归因瀑布。

写法上给分组判断：哪些偏离有解释力、凭什么；哪些是噪音、凭什么。都带数字。

**1.2 市场反应与分歧。** 公告后股价怎么走，为什么。如果市场反应与业绩方向相反（业绩超预期但股价跌），这一节就是全文最有价值的部分——把市场在担心什么写清楚，并说明本报告同意还是不同意。配公告前后股价图。

### 二、业绩拆解

全文最重的一章，篇幅约占正文三分之一。

**2.1 收入拆解。** 分部 / 地域 / 产品逐层往下，找到收入偏离的落点。每个分部给：本期值、YoY、QoQ、与此前预测的差异、趋势与前几期比。配分部并列柱、占比堆叠柱、增速对照。

**2.2 盈利能力。** 毛利率变动先归因到量、价、结构、成本四项中的哪几项；再看费用率，区分绝对额变化和收入摊薄。经营杠杆是否体现——收入增速与利润增速的差值本身就是结论。配毛利率趋势、费用率拆解。

**2.3 关键经营指标。** 公司自己强调的那几个量。这些指标常常比财务数字更早反映拐点，所以要看趋势不只看单期。配趋势图。

### 三、指引与展望

**3.1 新旧指引对照与可实现性。** 三个数并列：新指引、旧指引、一致预期。然后做反推——全年指引减去已实现部分，得出剩余期间的隐含增速，和刚过去这一季的实际增速比。这一步经常能看出指引是保守还是激进，是这一章的核心。配指引区间对照图和隐含增速图。

公司未给指引时，这一章缩成一节，写明未给指引，并基于本期结果和管理层表述给独立展望。不要替公司推一个指引区间。

**3.2 管理层表述的信号。** 语气、被反复追问的问题、首次提到的新说法、**不再提的旧说法**。最后这一项最容易漏也常常最有信息量——上一期反复强调、这一期一次没提的东西，通常出了问题。

### 四、投资逻辑更新

**4.1 逐条支柱评估。** 把原投资逻辑的每一条列出来，逐条标「强化 / 不变 / 削弱」，每条附本期的具体证据（带数字）。这一章是业绩更新区别于「财报数据罗列」的地方。

原投资逻辑来自上一份报告；拿不到时，在这一节开头写明用的是哪个版本的逻辑框架，或与用户确认。

**4.2 风险更新。** 只写变化：新识别的风险、已缓解的旧风险、已恶化的旧风险。没变的风险不重复列——完整清单在 5.3。

### 五、预测与估值更新

**5.1 预测更新。** 从 Excel `预测更新` sheet 摘表，旧 vs 新并排。每一项变动跟一句原因，原因是机制不是「基于业绩调整」。配预测修订并列柱和修订幅度条形图。

**5.2 估值与目标价。** 从阶段 3 估值稿取。三件事说清：目标倍数动没动及为什么、每股盈利变了多少、目标价新旧对照。然后是评级和上行空间。配估值区间图和敏感性图。

**5.3 风险提示。** 8–12 条，分类列（经营 / 财务 / 行业 / 政策 / 估值）。每条给机制不只给名词。

### 附：来源与参考资料

本期业绩公告、季报或年报、业绩会纪要、投资者演示材料、一致预期来源、上一期指引出处，每条带日期和可点击超链接。超链接写进 `document.xml.rels`，显示文本要有意义，正文里不出现裸 URL。

`_data` 底稿开头那节「数据源盘点」的摘要放在这一节末尾：检查过哪些来源、哪些可用、哪些数据项没有覆盖。

这一节是本 Skill 唯一保留的「附录类」内容。执业编号、评级体系图例、法律免责声明一律不放。

## 图表编号

原生 Word 表格和图片全部排定后，按正文顺序统一编号「图表 N」，全文连续不断号。图注在图下、8.5pt 加粗居中；来源在图内 7pt 灰，原生表格的来源放表内跨列末行。

首页和业绩速览页的表不进序列。

## 表格

- 每行设 `cantSplit`，防止单行被分页切成两半
- **不要给单元格段落设 `keepNext`**——Word 会在这类段落左侧画小黑方块格式标记，在单元格里贴着文字，看着像项目符号。`keepLines`、`pageBreakBefore` 同样不用
- 表宽一律 10546 DXA（全宽）或 5273 DXA（半宽），禁止 `tblW type="auto"`
- 口径小字放表内跨列末行，不写成表格外的独立段落

## 交付前核验

按 `Word文档格式标准.md` 的 15 步走一遍，其中：

- 第 12 步起必须渲染成 PDF/PNG 目视，结构校验代替不了
- 第 15 步跑渲染门：`python scripts/checks/check_render.py <pdf> --earnings`，五项断言（页数区间 14–18、无空白页、首页元素齐全、首页未溢出、文字未越出版心）全 PASS 才允许交付

再跑三个断言：

```bash
python scripts/checks/check_internal_labels.py <docx> <xlsx> <图表脚本>
python scripts/anti_fabrication_lint.py <图表脚本> <_data 底稿> <各阶段稿件>
# 从 document.xml 抽纯文本，断言 0 处「我们」、0 处 <w:keepNext>、0 处 <w:numPr>
```

最后对照 `../assets/质量检查清单.md` 全表核一遍，重点是「业绩更新专项」和「跨文件一致性」两节。

## 自检

- 14–18 页、6,000–9,000 字、18–25 图表全部嵌入
- 摘要第一句是「高于/低于预期 + 幅度」
- 旧 vs 新对照并排给出（预测、指引、目标价）
- 目标价变动或明确写「维持」；评级带变动方向
- 指引已分析或明确写「本期未给出指引」
- 投资逻辑逐条标了强化/不变/削弱
- 「来源与参考资料」齐全，超链接可点击，无裸 URL
- 没有公司背景介绍长篇
- 渲染门、内部代号门、反编造 lint 全 PASS
- DOCX 与 Excel 抽 10–15 个关键数核对一致
