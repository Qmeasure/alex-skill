# 阶段 2：预测更新

产物：`[公司]_预测更新_[日期].xlsx`。四张 sheet，带活公式，是阶段 3 估值和阶段 5 正文数字的唯一底座。

开始前完整读取内嵌 Excel Skill：`../anthropic_skills/xlsx/SKILL.md`。

## 这一阶段做什么、不做什么

**做**：把本期实际值灌进去，据此修正剩余期间和下一年的预测，逐项写清变动原因。

**不做**：重建完整三表模型。业绩更新是增量工作——首次覆盖版那套分部驱动量建模、三档情景、DCF 全套、历史回测，这里都不做。已有完整模型的（来自首次覆盖或上一期），在它上面改，不要重建一个。

如果这家公司从来没有过模型，也没有可对照的旧预测，回到 SKILL.md 的「没有旧预测怎么办」——先和用户确认基准，不要自己编一个旧预测。

## 四张 sheet

### 1. `本期实际与假设`

上半是本期实际值，逐项对照此前预测和一致预期（结构同阶段 1 的三口径表）。下半是修正后的关键假设，每条假设一行：假设值、依据、上一版取值、变了没有。

蓝色只在假设区。假设的依据要具体到可验证：「管理层在业绩会说四季度产能爬坡完成」比「预计产能改善」有用。

### 2. `预测更新`

本阶段的主表。至少覆盖本年和下一年，有把握的话加第三年：

| 指标 | 旧预测 | 新预测 | 变动幅度 | 变动原因 |
|---|---:|---:|---:|---|
| 营业收入 | | | | |
| 　分部 A | | | | |
| 　分部 B | | | | |
| 毛利率 | | | | bps |
| 经营利润 | | | | |
| 归母净利润 | | | | |
| 扣非 / non-GAAP 净利润 | | | | |
| EPS | | | | |

变动原因写机制，不写「基于本期业绩调整」——那等于没说。写成「四季度指引隐含增速 12%，低于此前假设的 18%，据此下调」这样，读者能判断你调得对不对。

新预测列必须是公式，引用 `本期实际与假设` 的蓝色假设，改假设全表重算。旧预测列是硬值（来自上一版），标注出处和日期。

### 3. `分部季度序列`

近 8–12 个季度的分部 / 地域收入、增速、利润率。这是阶段 4 大部分趋势图的数据源。

分部名用公司披露的名称，不自造、不缩写成代号。历史季度值来自公司过往披露，每个季度标出处。

### 4. `检查`

至少这几列，任一非 PASS 不得进入阶段 3：

- 本期实际值合计 = 各分部之和（允许「其他」项，但要显式列出）
- 新预测的分部之和 = 新预测总收入
- 毛利率、净利率由收入和利润重算，与直接填入值一致
- 旧预测列的出处已填（上一版文件名 + 日期）
- 变动幅度 = (新 − 旧) / 旧，公式重算
- 币种、单位、财年口径声明已填
- YoY / QoQ 增速的分母期间正确（单季对单季，累计对累计）

## 格式规范

- 配色：蓝=人工输入 / 黑=本表公式 / 绿=跨表引用
- 每个 sheet 冻结表头、标单位与基准日
- sheet 名和单元格文字用读者语言：`本期实际与假设`、`预测更新`、`分部季度序列`、`检查`，不用 `beat`/`miss`/`seg_A`/`cons` 这类工作代号（见 `../assets/研报写作规范.md`「工作代号不进交付物」）
- 币种、单位、财年截止在每个 sheet 顶部声明；财年非 12 月截止的专门标注
- recalc 跑通零错误；data_only 读回关键输出与手算一致

## 自检

对照 `../assets/质量检查清单.md` 的「阶段 2」节。重点：四张 sheet 齐、变动原因是机制不是套话、`检查` 全 PASS、无工作代号。
