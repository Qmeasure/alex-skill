# 同业对照

业绩更新里的同业比较只回答一个问题：**这一期的表现，是这家公司自己的事，还是整个行业都这样。**

这决定了差异归因的落点。收入低于预期 5%，如果三家同业同期都低 4%–6%，那是行业需求问题，公司经营没出错，投资逻辑不必大改；如果同业都符合预期只有它低，那是公司自己的问题，逻辑要重估。同一个数字，两种解释，投资含义完全相反。

## 这一节是可选的

**同业本期尚未披露业绩时，直接跳过并在正文写明**，比如「可比公司中仅 X 已披露本期业绩，样本不足以判断行业共性」。

**不得用旧季度数据凑一张表。** 拿同业上一季度的数和目标公司这一季度的数并列，比较的是两个不同的期间，得出的「同业表现更好」是假结论。宁可不做这一节。

## 不做什么

业绩更新不建首次覆盖版那套三层标的池（经营对标 / 估值可比 / 产业链主题），不做分位统计，不用同业倍数重新推导目标倍数。那些是从零建立估值锚的工作，业绩更新的估值锚沿用上一期（见 `阶段3-估值与评级更新.md`）。

同业数据在这里只作**归因证据**，不作**估值依据**。

## 怎么选样本

沿用上一期报告用过的可比公司名单，不重新筛。理由很简单：换了名单，同业对照的口径就和上一期不可比，读者无法判断相对位置的变化是真实的还是换样本造成的。

名单里有公司本期未披露的，标「未披露」留在表里，不删行也不换人补位。

上一期名单不可得时，选 2–4 家产品与终端场景直接重合的公司，在表下写明选取理由和主要不可比点。

硬要求：

- **报告期列必须有**，且各家的报告期要对齐到同一自然月份区间。财年不同的公司，写清各自的期间，对不齐的在表下注明，不硬当成同期。
- 未披露的填 `未披露`，不填 `—`（`—` 在本 Skill 的表里表示「取不到数」，两者含义不同）
- 币种不同的不换算，各标各的币种，只比增速和利润率这类无量纲指标
- 目标公司行高亮

## 结论怎么写

表后写 2–3 条判断，直接给分组结论：

- 哪些指标上目标公司与同业同向、幅度接近，这部分归因于行业，不改投资逻辑
- 哪些指标上明显偏离同业，这部分是公司自身变量，要落到具体机制
- 这组对照支持还是反驳本期的差异归因

不要只复述排名（「公司增速在三家中排第二」），也不要因为同业更差就把目标公司的下滑说成优势。落点是解释，不是排座次。
