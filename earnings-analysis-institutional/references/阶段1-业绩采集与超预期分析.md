# 阶段 1：业绩数据采集与超预期分析

产物：`[公司]_业绩速览_[日期].md`，外加 `_data` 底稿。这一阶段决定整份报告的地基——公告日拿错、一致预期口径拿错，后面四个阶段全部作废。

## 第一步：锁定报告期，不要推断

**训练数据会过时，按当前月份推断季度是这类分析的头号错误来源。** 按顺序做，不跳步：

1. **写下今天日期**，落进 `_data` 底稿。
2. **检索最新一期业绩**。检索词用「最新业绩」「最近季度业绩」这类，不要用「2026 年三季度业绩」——后者会让你在一个自己假设的季度上打转。也可以直接进公司投资者关系页的「新闻稿 / 业绩」栏目按日期排序取最上面那条。
3. **打开公告原文，读它自身的发布日期**，不要读搜索摘要里的日期。
4. **亲自算距今天多少天**。超过 90 天说明拿错季度，回第 2 步重新检索，不要在旧数据上继续。
5. **从标题和正文确认报告期**，同时核对季度名称和日期两者都是最新的。

红旗，任何一条为真就停下重来：公告日超过 90 天；说不出准确公告日；还没打开过公告原文只看了摘要；纪要写的季度与公告不一致；今天已是 2026 年而找到的公告是 2025 年或更早。

## 第二步：核对财年口径

确认报告期对应的自然月份区间。财年截止非 12 月的公司，「Q3」的含义与自然年完全不同：

| 公司类型 | 财年 Q1 | 财年截止 |
|---|---|---|
| 自然年 | 1–3 月 | 12 月 |
| Apple | 10–12 月 | 9 月 |
| Nike | 6–8 月 | 5 月 |
| Walmart | 2–4 月 | 1 月 |

这不是清单，是提醒：每次都要从公告页眉或公司披露里确认，不要按记忆套。报告里第一次出现报告期时写成 `3QFY2026A（2025-12 至 2026-02）`。

A 股还要额外确认**单季还是累计**。三季报披露的是前三季度累计，单季数要自己减。选定一个口径全篇用到底，在表下注明。

## 第三步：数据源盘点

`_data` 底稿开头先写这一节，再开始取数：

```
数据源盘点
- 用户放进工作目录的文件：
- 当前会话可用的检索与页面获取工具：
- 官方披露入口（IR 页 / 交易所平台 / EDGAR）：
- 一致预期来源与可得性：
- 已取到的：
- 取不到的，以及原因：
- 降级路径与影响：
```

这一节的摘要要进报告的「来源与参考资料」章节。取不到一致预期这类缺口，写在这里，不在正文里反复解释。

## 第四步：收集材料

**必需：**

- **业绩公告 / 新闻稿**——公司 IR 页。读原文取数字，不用媒体转述的整数。
- **季报 / 年报正文**——A 股巨潮资讯网，港股披露易，美股 SEC EDGAR（10-Q / 10-K）。财报表格是数字的最终依据；公告与财报对不上时以财报为准。注意披露文件通常晚于业绩公告 1–5 天。
- **业绩会纪要**——公司 IR 页、Seeking Alpha、AlphaStreet 等。**使用前先核日期**，必须与公告日 ±1 天匹配。纪要还没出的，听回放或注明待补。
- **一致预期**——**必须是公告前快照**，标明「截至 [公告前一交易日] 收盘」。公告后的一致预期已被这份业绩改写，用它算差异是用结果解释结果。取不到就在底稿标未覆盖，正文改用 vs 本报告此前预测的单口径对照并说明。

**补充（有则取）：** 投资者演示材料、补充数据表、管理层电话会问答。

**对照用：** 上一期业绩（算 QoQ）、去年同期（算 YoY）、上一期指引（比较指引变化）、本报告上一版预测（这是「旧预测」的来源）。

**行情：** 公告前一日收盘、公告后首个交易日收盘、12 个月日频逐日收盘序列。全部取交易所或行情接口的结算收盘，不用盘中价，原始序列落盘到底稿。

## 第五步：建三口径对照表

这是本阶段的核心产物，也是第 2 页那张表的来源：

| 经营利润 | | | | | | | |
| 归母净利润 | | | | | | | |

差异列：金额类给「绝对差（百分比差）」，利润率类给 bps。取不到的填 `—`，不留空、不编。

关键经营指标选公司自己在公告和业绩会里反复强调的那几个——用户数、ARPU、出货量、门店数、订单额、留存率，按行业选，不要套一个通用清单。

## 第六步：差异归因

对每个偏离预期的指标，回答四个问题，答案要落到具体科目或分部：

**高于预期时**：超的部分来自哪个分部、哪个科目？是一次性因素（汇兑、处置收益、退税、渠道压货）还是可持续因素（份额提升、提价、结构改善）？管理层有没有相应上调指引？这条对原投资逻辑是强化还是无关？

**低于预期时**：缺口出在哪里？是公司特有问题还是行业共性（同业是否同步下滑）？管理层给了什么纠偏动作和时间表？原投资逻辑哪一条被削弱？

写法上直接给分组判断——哪些差异有解释力、凭什么（带数字）；哪些是噪音、凭什么（带数字）。不写检索和筛选过程。

## 第七步：指引与业绩会

**指引**：新指引区间、旧指引区间（出处是上一期材料）、一致预期三者并列。反推指引隐含的剩余期间增速——比如全年指引减去已实现的前三季度，得出四季度隐含增速，再和刚过去这一季的实际增速比。这一步经常能看出指引的松紧程度。公司未给指引的，明确写「本期未给出指引」，不要替它推一个。

**业绩会**：记录管理层语气（自信 / 谨慎 / 防御）、被分析师反复追问的问题（这是市场的担心所在）、首次提到的新说法、以及**不再提的旧说法**——最后这一项最容易漏，也常常最有信息量。

## 稿件结构

`[公司]_业绩速览_[日期].md` 至少含：

1. 报告期与公告日（含自然月份区间、口径声明）
2. 三口径对照表
3. 逐项差异归因
4. 分部 / 地域拆分（本期、去年同期、上一期）
5. 关键经营指标与趋势
6. 指引对照与隐含增速反推
7. 业绩会要点
8. 市场反应（公告前后收盘、涨跌幅）
9. 数据缺口清单
