# 估值方法学

阶段 3 的理论参考。业绩更新的估值是**增量的**——方法沿用上一期，只换输入。这份文件讲清每种方法在业绩更新语境下要重算什么、哪些参数不该动，具体操作流程看 `阶段3-估值与评级更新.md`。

首次覆盖版里那套从零建可比公司池、算分位、做 SOTP 和足球场图的流程，业绩更新不做。硬要重建一遍，得到的目标价变化会混杂「业绩变了」和「尺子变了」两个来源，读者无法拆开看。

## 相对估值

核心是"同类资产同价"——找一组可比公司，看市场给它们什么倍数，套用到目标公司。

**常用倍数与适用场景**：

| 倍数 | 算法 | 适用 |
|------|------|------|
| PE | 市值 / 净利润 | 盈利稳定的成熟公司 |
| PEG | PE / 净利增速 | 成长股，剔除增速差异后比较 |
| EV/EBITDA | 企业价值 / EBITDA | 重资产、资本结构差异大的公司，剔除折旧和杠杆影响 |
| EV/Sales | 企业价值 / 收入 | 未盈利或利润不可比的高成长公司 |
| PB | 市值 / 净资产 | 银行、保险、地产等净资产驱动的行业 |
| PS | 市值 / 收入 | 软件、SaaS 等早期高成长 |

**业绩更新沿用上一期的可比公司名单，不重新筛。** 换名单会让目标倍数的变化混入样本变化，读者分不清倍数动了是因为业绩还是因为换了参照组。名单里本期数据不可得的公司，标注后保留在表里，不换人补位。

上一期名单不可得时，按这个优先级选：核心产品/服务 > 商业模式与利润驱动 > 周期与资本强度 > 同规模 > 同区域；并在报告里写明这是本期新建的名单，后续期间沿用。

**口径统一**：市值/EV 用同一行情日，跨市场换成同一展示币种；历史财务统一 LTM，预测倍数统一 FY1 或 NTM；GAAP/IFRS 与 adjusted 口径不混算。PE、PS 从市值和财务原值重算，数据商倍数只作交叉验证。负利润公司的 PE 写 `N/M` 并保留在表内，但不计入 PE 分位。

**倍数动不动，要单独交代。** 目标价 = 倍数 × 每股盈利。业绩更新里盈利预测几乎一定会变，倍数则未必——两者要分开说：

- 倍数不变、只有盈利变：最常见。说明业绩改变了盈利水平，但没改变市场应该给的估值档位
- 倍数也变了：必须给理由，且理由只能是这三类之一——增长中枢变了、风险特征变了、可比公司整体重估了。「业绩超预期所以上调倍数」不是理由，那是把同一件事在分子分母上算了两遍

**常见错误**：换了可比公司名单却不说明；把业绩超预期同时算进盈利上调和倍数上调（重复计算）；同一列混用 TTM 与 FY1；用公告前的股价算上行空间（市场已经消化了这份业绩）；本期有大额一次性损益却直接用报告口径利润套 PE；预测变动超过 5% 却维持目标价且不解释。

## DCF（现金流折现）

业绩更新里的 DCF 只更新前两三年的现金流预测，**WACC、永续增长率、终值倍数这些长期参数一律不动**，除非有明确的结构性理由（利率环境大变、资本结构大变、业务模式转型）。一期业绩不足以改变长期假设；把长期参数一起调，DCF 就成了凑目标价的工具。

绝对估值，把未来自由现金流折现到今天。理论上最严谨，但对假设极敏感，研报里多作佐证。

**步骤**：

1. **预测自由现金流（FCFF）**：FCFF = 税后经营利润（EBIT×(1−税率)）+ 折旧摊销 − 资本开支 − 营运资本增加。取阶段 2 模型的收入、利润、资本开支预测，不要另建一套
2. **算 WACC**：
   - 权益成本 Re = 无风险利率 Rf + β × 市场风险溢价（CAPM）
   - 债务成本 Rd = 实际融资利率 ×(1−税率)
   - WACC = Re ×(E/V) + Rd ×(D/V)，按市值口径的资本结构加权
   - 典型区间：成熟公司 8–10%，高成长/高风险 10–14%
3. **终值**：
   - 永续增长法：终值 = FCFF(末年+1) /(WACC − g)，永续增速 g 取 2–3%（不能高于长期 GDP 增速）
   - 退出倍数法：终值 = 末年 EBITDA × 退出 EV/EBITDA 倍数
   - 两种都算，交叉验证
4. **折现求和**：各年 FCFF 和终值按 WACC 折现到现值，加总得企业价值 EV → 减净负债 → 股权价值 → 除股本 → 每股内在价值
5. **敏感性分析**：做 WACC × 永续增长（或 WACC × 退出倍数）的目标价矩阵，配热力图。终值通常占 DCF 估值的 60–80%，所以这两个参数的微小变化会大幅改变结果，必须展示敏感性

**常见错误**：永续增速定太高（超过 GDP 长期增速）；WACC 凭主观设定、不拆解；FCF 和盈利模型口径不一致；只给一个点估值不给敏感性区间；终值占比过高还不做压力测试。

## 方法间怎么取舍

- 互联网平台、控股集团 → SOTP 主，相对估值和 DCF 辅
- 盈利稳定的成熟公司 → 相对估值（PE）主，DCF 辅
- 高成长扭亏中的科技公司 → DCF 或 PS/EV-Sales 主，待盈利稳定后切回 PE
- 周期股 → 看周期位置，PB 或正常化盈利的 PE，避免在周期高点用峰值利润套用 PE

业绩更新沿用上一期的主方法，不重新取舍。上一期用 PE 就继续用 PE。确有理由换方法时，同时给出新旧两种方法各自的结果，让读者看到目标价变化里有多少来自换方法。
