# 报告模板与版式

这份文件规定最终 DOCX 的信息编排：首页、业绩速览页、图表编号、章节骨架。版式机制（配色色值、字号行距、双栏 DXA 宽度、正文窄栏、页眉页脚构造）由 `../references/Word文档格式标准.md` 管，那份为准，这里不重复列数值。组装报告（阶段 5）前两份都要读。

版式对标外资投行研报的首页结构（左摘要 + 右投资数据栏），与首次覆盖版共用同一套网格；差别只在右栏放什么、第 2 页放什么、正文按什么逻辑链走。

## 首页

首页分三区，从上到下：品牌横幅 → 标题区 → 双栏区。页底不放表——业绩速览三表在第 2 页。

### 一区：品牌横幅

左 logo + 深蓝「智富界」，同行右端「业绩更新」+ 报告日期，下方亮蓝粗线。构造细节见格式标准的「机构标识」节。右端文案是「业绩更新」，不是首次覆盖版的「首次覆盖研究」。

### 二区：标题区

1. **主标题**。一句带判断的话，必须包含超预期/低于预期的方向和最关键的那个数——「收入超预期 3.2%，但指引隐含四季度零增长」「毛利率创八个季度新高，费用率同步抬升抵消大半」这类。大字加粗黑，独占一行或两行。不要写「XX 公司 2026 年三季度业绩点评」这种只报道不给判断的标题。
2. **副标题**。补充主标题的具体判断，灰色，字号小一档。主标题讲方向，副标题就讲这个方向能不能延续、卡在哪个变量上。
3. **股票标识 + 报告期**。公司全称 + 代码（拼多多 PDD.O / 腾讯控股 00700.HK / 寒武纪 688256.SH），加行业归类，再加报告期与公告日：`3QFY2026（2026-06 季）· 公告日 2026-08-14`。财年截止非 12 月的公司必须写出报告期对应的自然月份区间。

### 三区：双栏区

左栏（68%）放报告摘要，右栏（28%）放投资数据块。

**左栏——报告摘要**。全文最浓缩的版本，也是首页的主体，**要写满左栏版面**。**不单独写引言**，开头第一句直接给业绩结论加幅度（「收入 135.2 亿元，高于一致预期 3.2%；扣非净利低于一致预期 8.1%，收入与利润背离」），随后按「一 / 二 / 三 + 投资建议 + 风险提示」分层，每层用一句加粗判断领起，再展开 3–4 行给出机制和数字。层次结构对应正文逻辑链：业绩总览 / 拆解 / 指引，最后落到投资建议和风险提示。摘要之后正文直接从「一、业绩总览」起，没有独立引言段。

首页页底不放表（那三张表在第 2 页），左栏因此有充足版面。摘要写短了首页下半会空一大块——那是内容不足，不是留白设计。

**投资建议层和风险提示层各带一句固定的 AI 声明，文案写死，不逐份改写：**

- 投资建议层的加粗领起句固定为「**投资建议（AI 生成）：**[维持 / 上调 / 下调] [评级]，目标价 [币种+数值，变动时写「旧值 → 新值」，不变写「维持 币种+数值」]。」
- 风险提示层的最后一句固定为「本报告的预测、评级和目标价均由 AI 研究团队生成，未经人工分析师复核。」

风险提示层给最重的 4–6 条，每条带机制不只给名词；完整的 8–12 条留在正文 5.3，不另设第三处。

**右栏——投资数据块**。顺序固定，下表的元素一个都不能少、不能换位。**标签与数值统一 8pt 常规、两侧同字号、都不加粗**，层级只靠颜色（细则见 `../references/Word文档格式标准.md` 的「首页双栏」节）：

| # | 元素 | 说明 |
|---|------|------|
| — | **右栏左侧竖线** | 深蓝 `#1B3A6B` 细线，贯穿整个右栏，把投资数据区与左侧摘要分开。全文唯一的竖线 |
| 0 | **「AI 投资建议」区块标签** | 8pt 加粗亮蓝，下方亮蓝细线。压在评级 / 目标价 / 当前价 / 上行空间这四项之上，标明它们是 AI 生成的投资结论 |
| 1 | 评级 | 前缀写变动方向：`维持 增持` / `上调至 买入` / `下调至 中性`。档位用所在市场惯用的（A 股：买入/增持/中性/减持/卖出；港股美股可用 Buy/Hold/Sell 或对应中文）。亮蓝 `#2B6EF2` |
| 2 | 目标价 | 变动时写「旧值 → 新值」，不变写「维持 XXX」。带币种。亮蓝 `#2B6EF2` |
| 3 | 当前价 | 必须标日期，并注明是公告前还是公告后收盘，如「2026-08-15 收盘（公告后）」。深蓝 `#1B3A6B` |
| 4 | 上行空间 | =（目标价 − 当前价）/ 当前价，带正负号。深蓝 |

| 5 | 报告期 | 如「3QFY2026 · 公告 08-14」。深蓝 |
| 6 | 收入 vs 一致预期 | 带正负号的百分比，如「+3.2%」。取不到一致预期时改为「收入 vs 本报告预测」并在表下小字说明。深蓝 |
| 7 | EPS vs 一致预期 | 同上。口径（GAAP / non-GAAP / 扣非）与正文一致，标在标签里 |
| 8 | 总市值 | 币种随市场（美股 USD mn，A 股人民币亿元，港股 HKD 亿元）。深蓝 |
| 9 | 12 个月股价图 | 窄版，**宽度取满右栏可用宽度（约 4.7 cm），不要缩小**。**原始收盘价，不做归一化、不重设起点为 100**；日频逐日真实收盘；图内标最新价与 52 周高低。规格见 `../references/阶段4-图表生成.md` |
| 10 | 分隔线 + AI 研究团队块 | 亮蓝细线横贯右栏，其下见下 |

第 9 项替代了首次覆盖版的相对表现图。业绩更新的读者关心的是绝对价位和 52 周位置——这一期业绩落在什么价格水平上，离高点多远——不是跑赢跑输指数多少。

**AI 研究团队块**（分隔线以下，文案写死，不逐份改）：

```
AI 研究团队                       ← 小标题，加粗，亮蓝
本报告由 AI 生成                  ← 7pt 常规，灰
董AI                              ← 10pt 加粗
alex.dong@l2y.com                 ← 8pt 常规，灰
李菲特                            ← 10pt 加粗
lester.li@l2y.com                 ← 8pt 常规，灰
[二维码图片，宽 1.7–2.0 cm，以首页能收在一页为准]
扫码加入社群                      ← 居中，7pt 常规，灰
```

分析师默认就是董AI 和李菲特这两位，用户明确指定别的名字时才替换。二维码下方居中写「扫码加入社群」，文案固定，不改成「关注我们」「长按识别」这类变体。

## 第 2 页：业绩速览

整页数据，不写论述文字，**三块内容全部收在这一页**。字号 7.5pt、单元格上下边距 30 DXA。这一页替代首次覆盖版的 Key data 页。

**上半：三口径对照表**，占满 18.6 cm 版心。这是全份报告最重要的一张表——超预期/低于预期的全部依据都在这里。

差异列的写法：金额类给「绝对差（百分比差）」，利润率类给 bps。取不到一致预期的行填 `—`，不留空、不编。口径小字放表内跨列末行，写清币种、单季还是累计、GAAP 还是调整口径、一致预期的截止日。

**下半：无边框二列表格，每栏 9.3 cm**

- 右栏：**指引对照 + 预测更新摘要**——上半是新指引 vs 旧指引 vs 一致预期（公司未给指引时写「本期未给出指引」，整块保留不删）；下半是本年与下一年的收入、利润、EPS 的旧预测 / 新预测 / 变动幅度。

三张表的口径、币种、财年截止必须与阶段 2 的 Excel 完全一致。

## 合规样板

首页和全文都不放执业编号、评级体系图例、法律免责声明——这些是合规填充，本 Skill 一律省略。评级、目标价、风险提示要保留，它们是分析结论。

**「来源与参考资料」章节是例外，必须保留**——它列的是本期业绩公告、季报、业绩会纪要、投资者材料、一致预期来源和上一期指引出处，每条带日期和可点击超链接。这是实质内容不是合规填充：读者要能顺着链接回到原始材料复核数字。

## 图表编号与来源脚注

中文研报把图和表统一编号，叫「图表 N」，全文连续不断号（图表 1、图表 2、图表 3……不分图和表两套号）。业绩更新通常 18–25 个。阶段 4 的 PNG 使用稳定资产 ID、不预占编号；阶段 5 把原生 Word 表格和图片全部排定后，再按正文顺序统一编号。首页和业绩速览页的表不进入「图表 N」序列。

每个图表的规范：

- **标题在下**：「图表 N：[描述性标题]」，居中，带单位。
- **来源在图内**：小字 7pt 灰，写在图片内部，不在图注下方另起一行。原生 Word 表格的来源无法放进图内，放表内跨列末行。
- 完整的来源清单只放在「来源与参考资料」章节，不在每个图表下方堆叠。
- 只保留页码内容目录，不另做图表目录（list of figures）。

## 正文章节骨架

正文按业绩更新的逻辑链组织：先说这期是好是坏，再拆好坏从哪来，再看公司自己怎么看未来，再回头重估投资逻辑，最后落到预测、估值和风险。骨架是这套，具体章名按公司和本期业绩起，**给结论、带数字，不用比喻**（见 `研报写作规范.md`）：

```
一、业绩总览：[超预期/低于预期 + 幅度的判断式标题]
  1.1 三口径对照与差异归因——差异来自哪个科目、哪个分部、是一次性还是可持续
  1.2 市场反应与分歧——公告后股价反应，市场和本报告的分歧在哪一条

二、业绩拆解：[驱动来自哪里的判断式标题]
  2.1 收入拆解——分部 / 地域 / 产品，谁超谁欠，趋势与前几期比
  2.2 盈利能力——毛利率、费用率、经营杠杆，逐层归因
  2.3 关键经营指标——公司自己强调的那几个量，与预期和趋势对比

三、指引与展望：[对指引可实现性的判断式标题]
  3.1 新旧指引对照与可实现性——隐含的剩余期间增速反推
  3.2 管理层表述的信号——语气、被追问的问题、首次提到或不再提的东西

四、投资逻辑更新：[哪几条被改写的判断式标题]
  4.1 逐条支柱评估——每条原投资逻辑标「强化 / 不变 / 削弱」，附本期证据
  4.2 风险更新——新识别的风险、已缓解或已恶化的旧风险

五、预测与估值更新
  5.1 预测更新——旧 vs 新逐项对照 + 每项变动原因
  5.2 估值与目标价——用新预测重算，说明目标价变动或维持的依据
  5.3 风险提示——8–12 条，分类列

附：来源与参考资料
```

章节顺序基本固定——业绩更新的逻辑链比首次覆盖刚性，因为读者的问题序列是固定的。可以合并（比如指引很少时把第三章并进第二章），但不要打乱先后。

骨架里 1.1 / 5.1 这种子项名只是结构占位，**落到报告里的小标题要带判断，不要停在中性名词**（详见 `研报写作规范.md` 的「章节标题」节）。比如「收入拆解」这种中性标题，改成「超预期全部来自海外，国内同比转负」这类带数字带判断的。大标题小标题一视同仁。

带判断不等于带比喻。「利润表里长出了第二增长曲线」这类标题读者第一眼看不懂在说什么，是最典型的 AI 味来源。标题的唯一任务是让读者知道这一节的结论。

## 版面

字体、字号、行距、页边距、配色色值、正文窄栏、双栏宽度、表格、图注这些排版数值，统一以 `../references/Word文档格式标准.md` 为准，这里不另列一套。本文件只管业绩更新特有的部分：

- **图表配色**：全报告一套四色板，深藏青 `#1F3A6E` 主系列 + 珊瑚红 `#E15759` 次系列/强调/负值 + 中蓝 `#76A9E8` 第三系列 + 灰 `#9AA5B1` 辅助。柱用深藏青、线用珊瑚红，一冷一暖才拉得开；珊瑚红在同一张图里只承担一个角色。**业绩更新有一个固定用法**：超预期用深藏青、低于预期用珊瑚红，全文一致，读者扫一眼颜色就知道方向。图表配色独立于 Word 文字配色，不共用色值。细则见 `../references/阶段4-图表生成.md`。
- **版面密度**：正文 60–80% 版面有内容（图文表混排，不要大片留白），尽量每页都有图或表。避免「一页就一张图」或「标题下面没正文」。图配文、表配解读。
- **图和表必须占满宽度**：单张图或表铺满 18.6 cm 版心，成对的拼一行各占 9.3 cm。缩小后孤零零居中在页面中间是禁止项。成对/可对照的图（本期 vs 去年同期、旧预测 vs 新预测、收入超预期 vs 利润低于预期、毛利率 vs 费用率等）优先拼一行；两张原生表格同样可以拼一行。
- **旧新对照一律并置**：凡涉及「旧 vs 新」的内容（预测、指引、目标价），必须在同一张表或同一张图里并排给出，不得分成两处让读者自己翻页比对。

## 体量门槛

- 14–18 页
- 6,000–9,000 字中文正文
- 18–25 个图表全部嵌入（不是附在文件夹里）
- 关键财务表 4–8 张

达不到这些，说明内容没有充分展开，补充完善后再交付。用户明确限定范围（比如只要版式验证样张）时按用户范围执行，并说明未达完整体量的原因。

比首次覆盖版短，短在覆盖范围：不写公司沿革、不写行业空间、不写股权治理、不做三层标的池和分位统计。不短在分析密度——差异归因、指引反推、逻辑重估这三块要写透。
