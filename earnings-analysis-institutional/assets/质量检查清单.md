# 质量检查清单

交付前逐项核对。分阶段列，每阶段产物落地时先核对本阶段的，最终报告交付前再核对全表一遍。任一项不达标，补充完善后再交付。

## 交付前阻断项（和渲染级 QA 同级，不过不交付）

这几条是硬门，不是软标准。

- [ ] 跑 `scripts/anti_fabrication_lint.py`（图表构建脚本 + 各 `_data` 底稿 + 稿件）通过，命中已逐条清除
- [ ] 正文和图表里每个数都能在 `_data` 底稿溯源（数值、口径、时间点、来源对得上），没有底稿外的数
- [ ] 没有合成 / 插值 / 示意 / 凑数的数据；缺数的地方是留空或标「未获取」，不是编一个值
- [ ] 现价、市值、指数等时效数据取的是结算日线收盘一手源，不是盘中价或搜索摘要
- [ ] **业绩公告日已亲自核算，距今 ≤3 个月**；今天日期和公告日都写在 `_data` 底稿里
- [ ] **一致预期是公告前快照**，标了「截至 [公告前一交易日] 收盘」；取不到时已在底稿标为未覆盖，正文改单口径对照并说明，没有拿公告后的数冒充
- [ ] DOCX 渲染成 PDF/PNG 做过视觉核验

## 阶段 1 业绩速览稿

- [ ] 今天日期已写下；业绩公告日已从公告原文读取（不是按月份推断），并算过距今天数
- [ ] 业绩会纪要日期与公告日期匹配（±1 天）；对不上的已重新检索
- [ ] 报告期写清楚了：`3QFY2026A` 加自然月份区间；财年截止非 12 月的已专门标注
- [ ] 单季 / 累计口径已选定并全稿一致，表下注明
- [ ] 三口径对照表完整：本期实际 / 本报告此前预测 / 一致预期 / 去年同期，差异列金额给「绝对差（百分比差）」、利润率给 bps
- [ ] 没有旧预测时，已告知用户并确认替代基准（一致预期或先做首次覆盖），不是自己编一个旧预测
- [ ] 差异归因写到科目和分部层面，区分了一次性因素与可持续因素
- [ ] 指引已抓取：新指引、旧指引出处（上一期材料）、一致预期三者齐；公司未给指引的已明确写「本期未给出指引」
- [ ] 业绩会要点已提取：管理层语气、被反复追问的问题、首次提到或不再提的东西
- [ ] 公告前一日收盘价与公告后首个交易日收盘价都已取到（市场反应是报告要解释的对象）
- [ ] 每个关键数字有来源和日期，关键数据双源（且双源异源，非转引同一篇）
- [ ] 建了 `_data` 底稿（五字段）+ 开头的「数据源盘点」一节；每个进稿数字能溯源
- [ ] 全文无 AI 味（对照 `研报写作规范.md` 自检）

## 阶段 2 预测更新表（Excel）

- [ ] 四张 sheet 齐：`本期实际与假设`、`预测更新`、`分部季度序列`、`检查`
- [ ] `预测更新` 含旧预测 / 新预测 / 变动幅度 / 变动原因四列，每行原因是具体机制不是「基于业绩调整」
- [ ] 蓝色输入只在假设区，每条假设有依据；模型页为联动公式，改假设全表重算
- [ ] 配色规范：蓝=输入 / 黑=本表公式 / 绿=跨表引用
- [ ] `分部季度序列` 覆盖近 8–12 个季度，口径与公司披露一致，分部名用披露名
- [ ] `检查` sheet 的重算差、口径一致性、合计校验全 PASS
- [ ] recalc 零错误；data_only 读回关键输出与手算一致
- [ ] 币种、单位、财年口径已声明（财年非 12 月截止的专门标注）
- [ ] sheet 名和单元格文字里没有 `beat`/`miss`/`seg_A`/`cons` 这类工作代号

## 阶段 3 估值与评级更新

- [ ] 用**新预测**重算估值，不是沿用旧数
- [ ] 目标价明确给出：变动的写「旧 → 新」并说明驱动（哪个预测项变了多少、倍数变没变）；不变的明确写「维持」并说明为什么业绩变化不足以改变目标价
- [ ] 评级明确给出：维持 / 上调 / 下调，变动的有理由（不只是「业绩超预期所以上调」，要落到风险收益比）
- [ ] 预测变动 >5% 却维持目标价的，已解释为什么
- [ ] 估值方法与上一期保持一致；换方法的已说明换的理由
- [ ] 上行空间 =（目标价 − 当前价）/ 当前价，当前价标了日期和公告前后

## 阶段 4 图表

- [ ] 18–25 张，全部有真实数据支撑；数据不足未达 18 张的已说明原因
- [ ] 必备图齐：季度收入与超预期、季度 EPS 与超预期、利润率趋势、分部拆分、关键经营指标、差异归因瀑布、预测修订前后对比、估值区间、12 个月股价图
- [ ] **12 个月股价图是原始收盘价**，未归一化、未重设起点为 100；图内标最新价与 52 周高低；日频逐日真实收盘，无周频重采样或插值
- [ ] 超预期用深藏青、低于预期用珊瑚红，全文一致
- [ ] 四色板生效（#1F3A6E / #E15759 / #76A9E8 / #9AA5B1）；柱深藏青、线珊瑚红；珊瑚红在同一张图里只担一个角色
- [ ] 任何图表都没有网格线；直角坐标图无上/右边线，X/Y 实线在
- [ ] 来源写在图内，7pt #666666；图下只有「图表 N：<主题>」
- [ ] 中文标题、轴标签、图例渲染正常，无乱码、无重叠
- [ ] 300 DPI；单图源图宽 7.33 in，成对图源图宽 3.66 in

## 业绩更新专项

- [ ] 全文第一个结论出现在摘要第一句，是「高于/低于预期 + 幅度」
- [ ] 每个「超预期」「低于预期」都跟了幅度和口径（vs 一致预期 还是 vs 本报告此前预测）
- [ ] 方向词全篇统一三档：高于预期 / 低于预期 / 符合预期，没有「beat」「好于预期」混用
- [ ] **旧 vs 新对照并排给出**（预测、指引、目标价），没有分散在两处让读者翻页比对
- [ ] 每项预测变动都有变动原因，不是只给新数
- [ ] 目标价变动或明确写「维持」，二者必居其一，没有含糊带过
- [ ] 评级的变动方向写在标签里（维持 / 上调至 / 下调至）
- [ ] 指引已分析（隐含的剩余期间增速已反推），或明确写「本期未给出指引」
- [ ] 投资逻辑逐条标了「强化 / 不变 / 削弱」，每条附本期证据
- [ ] 公告后股价反应已解释，市场与本报告的分歧点已写明
- [ ] 同业对照：同业已披露的做了横向表；未披露的直接说明跳过，**没有用旧季度数据凑表**
- [ ] 没有做三层标的池、分位统计或用同业倍数重定目标倍数（那是首次覆盖的活）
