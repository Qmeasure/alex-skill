# 口语词清单

配合 `SKILL.md` 第三步使用。清理转录稿时**唯一允许的减法**就是这张表里的词，别的一个字都不能动。

分三档：第一档闭着眼删，第二档要判断，第三档碰都不要碰。

---

## 第一档：无条件删

纯声音，不携带任何语义。出现在句首、句中、句末都删，连同它带的标点一起删。

### 中文叹词

嗯、嗯嗯、嗯哼、呃、呃啊、额、诶、欸、唉、哎、哎呀、啊、啊这、哦、噢、喔、呀、哇、咦、唔、嘿、嗐、哈（单独作语气时）

### 英文填充音

um、umm、uh、uhh、er、erm、ah、mm、mmm、hmm、huh

### 拟声犹豫

那个……（拖长音、后面接停顿而非名词时，见第二档判据）、这个……（同上）

### 例子

| 原文 | 清理后 |
|---|---|
| 嗯，我觉得这个判断是对的。 | 我觉得这个判断是对的。 |
| 我们呃，我们去年就看过。 | 我们，我们去年就看过。→ 逐字重复合并 → 我们去年就看过。 |
| 啊这个，怎么说呢，哦对，是三千万。 | 这个，怎么说呢，对，是三千万。→ 二档再处理 → 对，是三千万。 |
| So um, I think basically it's a timing issue. | So I think it's a timing issue.（`um` 一档删，`basically` 二档判断） |

## 第二档：看语境删

这些词**有时是纯填充，有时承载逻辑**。删之前必须问一句：

> **去掉之后，句子的意思和逻辑关系变了吗？**

变了就留，没变才删。**拿不准一律留**——保真的优先级高于流畅。

### 完整词表

**句首启动类**：然后、那、那么、就是、就是说、所以说、反正、其实、说白了、怎么说呢、我的意思是、我想说的是

**指示填充类**：这个、那个、这种、那种、什么的、之类的、blabla

**程度模糊类**：基本上、某种程度上、一定程度上、多多少少、大概、有点、稍微（注意：表真实不确定时属第三档，见下）

**确认回访类**：对吧、是吧、对不对、你知道吗、你懂吧、你明白吗、明白吧、是不是、好吧

**句末缓冲类**：嘛、呢（部分）、哈、这样子、这样、就这样、什么的

**英文**：like、you know、I mean、sort of、kind of、basically、actually、literally、right?、okay so、well

### 逐词判据

#### 然后

| 情况 | 判定 | 例子 |
|---|---|---|
| 表时间/逻辑顺承 | **留** | 「先谈了两轮，然后签了 TS」 |
| 句首纯启动 | **删** | 「然后我觉得这个事没那么简单」→「我觉得这个事没那么简单」 |
| 连续多个"然后"串句 | 保留第一个表顺承的，其余删 | 「然后我们看了，然后觉得不行，然后就撤了」→「我们看了，觉得不行，然后就撤了」 |

#### 就是 / 就是说

| 情况 | 判定 | 例子 |
|---|---|---|
| 表"也就是说"，引出解释 | **留** | 「他说的是估值倒挂，就是说一级比二级贵」 |
| 纯填充 | **删** | 「这个就是，就是我觉得吧，不太合理」→「这个我觉得不太合理」 |
| 「就是」表强调"正是" | **留** | 「问题就是出在这儿」 |

#### 这个 / 那个

| 情况 | 判定 | 例子 |
|---|---|---|
| 指示具体事物 | **留** | 「这个市场今年会变」「那个项目我们没投」 |
| 后面接停顿，纯拖延 | **删** | 「这个……我觉得吧」→「我觉得」 |
| 「那个谁」指代人 | **留** | 「那个谁，老张，他说过」 |

#### 其实

| 情况 | 判定 | 例子 |
|---|---|---|
| 表转折、纠正预期 | **留** | 「看着贵，其实不贵」 |
| 句首填充 | **删** | 「其实我们一直在看这个方向」→「我们一直在看这个方向」 |

判断窍门：前面有没有一个被"其实"推翻的预期？有就留。

#### 反正

| 情况 | 判定 | 例子 |
|---|---|---|
| 表"无论如何" | **留** | 「反正今年是投不了了」 |
| 纯填充 | **删** | 「反正我觉得吧，还得再看看」→「我觉得还得再看看」 |

#### 基本上 / 某种程度上

| 情况 | 判定 | 例子 |
|---|---|---|
| 真的在限定范围 | **留** | 「基本上头部三家占了八成」 |
| 口头禅式滥用 | **删** | 「基本上我觉得基本上是这样」→「我觉得是这样」 |

#### 对吧 / 是吧 / 你知道吗

| 情况 | 判定 | 例子 |
|---|---|---|
| 真在征求确认，对方接了话 | **留** | 「这个逻辑成立吧？」——对方答「成立」 |
| 句末口头禅，没人应答 | **删** | 「这个市场变了对吧，然后大家都在等对吧」→「这个市场变了，大家都在等」 |

#### 嘛 / 呢 / 哈

| 情况 | 判定 | 例子 |
|---|---|---|
| 「嘛」表理所当然的语气 | **留**（改变语气就是改变内容） | 「本来就是这样嘛」 |
| 「嘛」纯句末缓冲 | **删** | 「这个事嘛，我们再看看」→「这个事我们再看看」 |
| 「呢」构成疑问 | **留** | 「那估值呢？」 |
| 「呢」句中停顿 | **删** | 「我呢，是这么看的」→「我是这么看的」 |

#### like / you know / I mean

英文口语填充，中英混说时很常见。

| 情况 | 判定 | 例子 |
|---|---|---|
| `like` 表"比如/像" | **留** | 「像 like OpenAI 这种公司」 |
| `like` 纯填充 | **删** | 「it's like, you know, a timing thing」→「it's a timing thing」 |
| `I mean` 引出澄清 | **留** | 「三亿，I mean 三千万」 |
| `I mean` 句首填充 | **删** | 「I mean, 我觉得没问题」→「我觉得没问题」 |
| `actually` 表转折 | **留** | 「看着贵，actually 不贵」 |
| `actually` 填充 | **删** | 「actually 我们上周聊过」→「我们上周聊过」 |

## 第三档：永远保留

碰都不要碰。这些看起来像口语，其实全是内容。

### 语气强度词

**非常、特别、极其、超级、相当、挺、蛮、有点、稍微、略微、太、真的、确实**

理由：它们改变判断的强度。「有点贵」和「贵」是两个不同的判断，删掉就是篡改。

> ❌ 「这个估值有点高」→「这个估值高」
> ✅ 原样保留

### 不确定表述

**我不太确定、我不知道、大概、可能、也许、应该是、感觉、印象中、如果我没记错**

理由：删掉会把猜测变成断言。这是最危险的一类失真。

> ❌ 「大概是三千万吧」→「是三千万」
> ✅ 「大概是三千万」（句末的「吧」可按二档判断，但「大概」必须留）

### 自我更正

**「是三亿，不对，是三千万」——两个数字都留，「不对」也留。**

理由：那是真实发生的更正过程。只留结果会抹掉「说话人当场纠正了自己」这个事实，而这在访谈里往往很重要。

> ❌ 「是三千万」
> ✅ 「是三亿，不对，是三千万」

同类：「我们投了 A 轮——哦不是，是天使轮」

### 所有实词

名词、动词、形容词、数字、专有名词、机构名、时间、地点。**哪怕句子说得不通顺**。

> ❌ 「我们那个市场吧看了两年这个赛道」→「我们看了这个赛道两年」（调语序了，违规）
> ✅ 「我们那个市场吧看了两年这个赛道」→「我们市场看了两年这个赛道」（只删了二档的「那个」「吧」「这个」，语序没动）

### 情绪表达

**脏话、笑声标注、感叹、抱怨**，原样保留。那是说话人的真实语气。

> 「这价格简直离谱」——留
> 「（笑）这个我不好说」——留

### 重复表达同一意思的两句话

「这事儿不靠谱。真的，一点都不靠谱。」——这是强调，不是冗余。全留。

只有**逐字完全相同**的即时重复才合并（见下）。

---

## 逐字重复的合并规则

唯一允许的第二种减法，条件很严：**逐字相同，中间没有任何新信息。**

| 原文 | 判定 | 结果 |
|---|---|---|
| 这个市场、这个市场今年会变 | 逐字重复 | 这个市场今年会变 |
| 我们、我们去年看过 | 逐字重复 | 我们去年看过 |
| 这个市场，我是说一级市场，今年会变 | 中间有新信息 | **全留** |
| 不靠谱，真的不靠谱 | 不是逐字相同（多了「真的」） | **全留** |
| 三千万，三千万左右吧 | 不是逐字相同 | **全留** |

拿不准就留。

## 完整对照实例

**原文（转录稿）**

```
[00:12:04] S1  嗯，那个，我们看这个赛道呢，其实看了两年了，对吧。
[00:12:11] S1  最开始的判断吧，就是说，一年内会有拐点，然后现在回头看，那个判断太乐观了。
[00:12:19] S1  去年整个赛道融资额是三亿，呃，不对，是三千万。基本上，就是说，差了十倍。
[00:12:28] S0  那你觉得，呃，什么时候能有拐点呢？
```

**清理后（保留原语序、原用词）**

```
**嘉宾 A**：我们看这个赛道，其实看了两年了。

最开始的判断，一年内会有拐点，然后现在回头看，那个判断太乐观了。

去年整个赛道融资额是三亿，不对，是三千万。基本上差了十倍。

**主持人**：那你觉得什么时候能有拐点呢？
```

逐条对账：

| 处理 | 词 | 依据 |
|---|---|---|
| 删 | 嗯、呃 | 一档 |
| 删 | 那个（句首拖延）、呢（句中）、对吧（句末口头禅）、吧（「判断吧」）、就是说（填充） | 二档判断为填充 |
| **留** | 其实 | 二档，表转折（"看了两年"超出预期） |
| **留** | 然后 | 二档，表顺承 |
| **留** | 那个判断 | 二档，指示词 |
| **留** | 三亿，不对，是三千万 | 三档，自我更正 |
| **留** | 基本上 | 二档，真的在限定（差了十倍是约数） |
| **留** | 太乐观了 | 三档，语气强度 |
| 合并 | 说话人 S1 三行 | 同一人连续发言 |
| 丢弃 | 12:11、12:19 两个时间戳 | 只有章节起始时间进标题 |

注意「其实」「然后」「基本上」三个词在这里都**留**了——它们都在二档表里，但语境判定为承载语义。这就是二档的意义：**表在这儿不是删除清单，是判断清单。**
